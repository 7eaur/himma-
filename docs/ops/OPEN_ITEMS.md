# البنود المفتوحة

حُسم OI-01 الخاص بعدد الأصوات في ADR-003، وحُسم OI-09 الخاص بالصف الدراسي وسجل الطالب في ADR-010.

| المعرّف | البند | هل يوقف البناء؟ | نقطة الحسم |
|---|---|---:|---|
| OI-02 | مزود/وحدة التحليل الصوتي وعقدها، وحسم الانتقال من المراجعة البشرية الحالية إلى التحليل الآلي الذي طلبه العميل | لا للمراحل 0–3؛ نعم للمرحلة 4 | قبل بدء المرحلة 4 |
| OI-03 | حد الثقة | لا؛ إعداد غير مثبت | بعد معايرة أصوات ممثلة وقبل الدراسة |
| OI-04 | مدة التدخل وعدد الجلسات ومدتها | لا؛ إعداد قابل للتثبيت | قبل تفعيل الدراسة |
| OI-05 | مدة الاحتفاظ بتسجيلات الأطفال | لا للبناء؛ نعم للإطلاق | قبل تخزين بيانات أطفال حقيقية |
| OI-06 | الدومين وحسابات الاستضافة | لا للبناء؛ نعم للنشر | المرحلة 6 |
| OI-07 | بيانات وشعارات الجهة المشرفة | لا | قبل اعتماد التقارير النهائية |
| OI-08 | نُقّحت القيم المكشوفة من الشجرة الحالية، لكن يجب تدوير أي قيمة استُخدمت فعليًا لأن التاريخ العام قد يحتوي النسخة السابقة | لا يوقف baseline بقيم اختبار جديدة؛ يوقف الإنتاج والنشر | قبل أي نشر أو إعادة استخدام لبيئة الجهاز |
| OI-10 | المحتوى المعتمد يتطلب صوت «موز» وصوت المقطع «سَا»، بينما حزمة `HIMMA_AUDIO_V1` تحتوي «موزة» ولا تحتوي «سَا» | لا يوقف B01 لأن النقص معلن وممنوع الاستبدال؛ يوقف تفعيل جولتي `L1-CORE-06-R01` و`L2-CORE-06-R04` | إصدار صوتي معتمد جديد قبل تفعيل الجولتين |

لا تسأل المستخدم عن هذه البنود في كل مرحلة. ارجع إلى الجدول واسأل عند «نقطة الحسم» فقط.
