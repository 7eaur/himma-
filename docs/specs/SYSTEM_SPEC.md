# مواصفات النظام الحالية — منصة هِمّة

**Updated:** 2026-09-18  
مرجع الحقيقة: docs/specs/SOURCE_OF_TRUTH.md

## المنتج

منصة ويب عربية RTL لطلاب الصف الثالث ذوي صعوبات القراءة، مع سطح طالب وسطح مشرف. السعة الافتراضية 50 طالبًا.

## رحلة الطالب

1. دخول بكود أنشأه المشرف.
2. اختبار قبلي: 30 بندًا.
3. التوزيع الأولي من الدرجة النهائية:
   - <50 → L1
   - 50..<80 → L2
   - >=80 → L3
4. يبدأ من المستوى المسند فقط؛ الأدنى متجاوز بالتسكين.
5. النشاط:
   - >=80 نجاح.
   - 70..<80 إعادة موجهة.
   - <70 تقوية مستهدفة بنفس المستوى.
6. التكيف يستخدم أحدث 3 أدلة صالحة من Core session النشطة بأوزان 50/30/20.
7. L1/L2 early promotion: 6 Core على الأقل + mastery >=85 + critical coverage + critical floor >=70 + no unresolved reinforcement/audio review.
8. لا automatic demotion.
9. L3 يتطلب 10 Core، وهو المستوى النهائي.
10. البعدي: 30 بندًا، بعد اكتمال التعلم وتفعيل المشرف.
11. واجهة الطفل تعرض مهمة واحدة وإجراءًا أساسيًا واحدًا وتجنب تشخيص/وصم الطفل.

## رحلة المشرف

- تسجيل دخول محمي.
- إنشاء/إدارة الطلاب والأكواد ضمن السعة.
- متابعة الحالة/المستوى/الرحلة.
- مراجعة تسجيلات القراءة واعتمادها أو طلب إعادة تسجيل.
- تغيير مستوى يدوي بسبب موثق عندما تسمح حالة الطالب.
- إدارة/معاينة المحتوى.
- التقارير ومؤشرات المهارات.
- الإعدادات والحساب.
- تفعيل البعدي وفق العقد.

## عقد الصوت الحالي

التسجيل:
captured → persisted/uploaded → human supervisor review → graded أو rerecord_required.

القواعد المهمة:
- pending/uploaded ليس نجاحًا ولا خطأً أكاديميًا.
- إذا بقيت أسئلة في الاختبار، رفع تسجيل لا يوقف الانتقال إلى السؤال التالي.
- لا تُنهى الجلسة أكاديميًا نهائيًا حتى تُحسم المراجعات المطلوبة.
- rerecord_required ينشئ مهمة صريحة مستقلة؛ لا يعيد الطالب تلقائيًا إلى السؤال/النشاط ولا يخطف current work.
- عند فتح مهمة إعادة التسجيل، يسجل محاولة جديدة مع حفظ التسجيل السابق كتاريخ.
- لا Student/Temporary Audio Skip.
- Human Supervisor Review هي السلطة الأكاديمية الحالية.
- ASR الآلي مستقبلي/مساعد وغير داخل الإغلاق الحالي.

## المحتوى

Runtime:
- Pretest: 30
- Posttest: 30
- Core: 30
- Reinforcement: 35
- Total: 125
- Skills: 44

Baseline catalog الأصلي = 105؛ الزيادة 20 تقوية versioned معتمدة.

قوالب التفاعل تشمل اختيار، سماع ثم اختيار، ترتيب، بناء كلمة، مطابقة، تسجيل قراءة، وفهم. لا تعتمد مهام إنشائية حرة أو رسم/تتبع حر ضمن V1 الحالي.

## التقنية

Frontend: Next.js 16 + React 19 + TypeScript + Tailwind.  
Backend: FastAPI + SQLAlchemy + PostgreSQL + Alembic.  
Coordination: Redis.  
Private media: object storage.  
Deployment: Railway.

الواجهة لا تتصل بقاعدة البيانات مباشرة ولا تعيد حساب قواعد المجال المرجعية.

## الخصوصية

- أقل قدر من بيانات الطفل.
- لا real child data أو recordings في Git.
- تسجيلات خاصة وروابط وصول محمية/مؤقتة.
- الاحتفاظ النهائي ببيانات الأطفال يحتاج اعتمادًا قبل دراسة حقيقية.
- لا تدريب خارجي على التسجيلات دون موافقة مستقلة.

## التقارير والمؤشرات

- القبلي/البعدي = earned / possible × 100.
- التحسن = post − pre.
- نسبة التحسن لا تحسب عندما pre = 0.
- تفاصيل التشخيص الأكاديمي تظهر للمشرف لا للطفل.
- أي WER/phonemic/ASR metric لا يصبح سلطة أكاديمية قبل اعتماد مزود ومعايرة مستقلة.
