# VID-L1-01 — سيناريو الإنتاج ذو خمسة مشاهد (اعتماد تربوي، قبل التوليد)
تاريخ: 2026-10-18
الحالة: المالك اعتمد التحسينات التربوية وطلب إعادة الصياغة إلى خمسة مشاهد مفصلة. هذه الخطة للإرسال إلى Gemini بعد تدقيق المنصة والميزانية، ولا تعني الموافقة على توليد محدود الرصيد.

## الثوابت
- الفيديو: الحرف وصوته، الهدف: ربط الحرف بصوته عند رؤيته أو سماعه، والتمييز بين اسم الحرف وصوته.
- الهوية: استوديو 2D المعتمد في المحادثة؛ ولد ذو نظارة زرقاء وهودي أزرق، مكتب بسيط ولوحة كبيرة وشعار همة. المرجع الرسمي للشخصية والشعار والصور موجود بالمستودع.
- الأمثلة المعتمدة: م — مَوْز، ب — بَاب، س — سَمَك.
- Gemini يتولى كتابة العناصر العربية والحركة والتعليق وفق طلب المالك؛ كل مخرج يُدقق بصريا وصوتيا قبل اعتماده.
- الثبات: نفس الشخصية والكاميرا والشعار؛ لا 3D أو حركات مشتتة. نموذج التوليد ومدة المقاطع وتكلفتها تُتحقق قبل التنفيذ.
