# هِمّة V2 — عقد محتوى الدرس

**الحالة:** معتمد

## Core Lesson

كل درس يجب أن يكون وحدة تعليم فعلية:

```text
1. تمهيد قصير
2. شرح المفهوم/الاستراتيجية
3. أمثلة محلولة متعددة ومتنوعة
4. تدريب موجه
5. تطبيق جديد عند الحاجة
6. خلاصة قصيرة
7. تحقق مستقل
```

## الأمثلة

- لا يشرح درس كامل بمثال واحد.
- عدد الأمثلة يتغير حسب طبيعة المهارة.
- الحركات والمدود والدمج تحتاج تنوعًا أكبر.
- أمثلة التحقق جديدة قدر الإمكان.
- الهدف قياس انتقال التعلم لا حفظ المثال.

## الوسائط

- الفيديو ليس إلزاميًا لكل درس.
- الصوت أساسي عندما تكون المهارة صوتية.
- الصور تستخدم للمعنى أو التمييز فقط.
- التفاعل يستخدم للبناء والترتيب والمطابقة.
- الكتابة الفعلية تستخدم عندما يكون الهدف كتابيًا.
- التسجيل يستخدم عندما نحتاج دليلًا على نطق الطالب.

## Micro-animation

يفيد خصوصًا عندما نحتاج شرح عملية:
- تغير صوت الحرف بالحركة.
- قراءة المقطع.
- الدمج.
- المدود.

لا نستخدم فيديو طويل لمجرد جعل الدرس "فيديو".

## الفهم

في التعليم والتدريب يمكن استخدام الصوت كدعم.

إذا كان Independent Check يقيس فهم المقروء، لا يشغل النص صوتيًا تلقائيًا؛ وإلا نكون نقيس فهمًا مسموعًا.

## Support Lesson

```text
تحديد الفجوة
→ شرح مركز
→ أمثلة جديدة
→ تدريب موجه
→ تطبيق قصير
→ 2–3 بنود تحقق
```

الدعم يعالج الجزء الضعيف فقط ولا يعيد الوحدة كاملة.
