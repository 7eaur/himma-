# هِمّة V2 — عقد محتوى الدرس

**الحالة:** معتمد — تحديث القالب 2026-10-15  
**المواصفة التنفيذية لبنك المحتوى:** `13_CONTENT_BANK_AND_UNIFIED_TEMPLATES_AR.md`

## قالب الطالب الموحد

```text
1. تمهيد قصير + التالي
2. فيديو تعليمي رئيسي يضم الشرح والأمثلة المتعددة والخلاصة
3. تدريب موجه بأسئلة وتلميحات وإعادة محاولة (ويشمل تطبيقًا جديدًا عند الحاجة)
4. اختبار مستقل للدرس بلا تلميحات كاشفة
```

هذا **قالب عرض واحد** للـ19 درسًا، والمحتوى يتغير من البنك دون كتابة واجهة خاصة لكل درس. المثال الواحد لا يكفي لشرح مهارة كاملة؛ تنوع الأمثلة يُخطط ضمن سيناريو الفيديو نفسه.

## تأليف الفيديو

- لكل درس أساسي مرجع فيديو رئيسي في البنك.
- نكتب قبل الإنتاج: هدف الدرس، سيناريو المشاهد، النص التعليمي، الأمثلة، وما يظهر بصريًا.
- لا نجعل لكل مثال شاشة أو فيديو مستقلًا.
- حالة الوسيط تُسجل بصراحة (`to_produce`, `pending_review`, `approved`).
- قد يبدأ تأليف الدرس مع فيديو لم يُنتج، لكن **لا يُنشر قبل توفير الفيديو المعتمد**.
- الصوت أساسي عندما تكون المهارة صوتية، والصور والتفاعل أدوات مساعدة وليست واجهات دروس مختلفة.

## التدريب

- سؤال واحد في كل مرة.
- التلميح والتصحيح وإعادة المحاولة مسموحة.
- يتم تسجيل استخدام التلميحات والأخطاء التعليمية لأغراض المتابعة لا باعتبارها درجة الاختبار.
- التطبيق الجديد، عند الحاجة، بند تدريب غير مستقل.

## اختبار الدرس

- 3–5 بنود، الافتراضي 4.
- له بنك منفصل عن أمثلة الفيديو والتدريب.
- لا تلميحات تعليمية تكشف الحل داخل البند.
- لا تُرسل الإجابات الصحيحة مع بيانات العرض للطالب قبل الإجابة.
- مهام القراءة/الكتابة تستخدم معيار تقييم مناسبًا عند الحاجة، ولا تفترض أنها اختيارات متعددة.

## قالب الدعم

```text
تمهيد مركز → شرح علاجي (فيديو/وسيط مناسب) → تدريب بالتلميحات → تحقق قصير (2–3)
```

يرتبط الدعم بـ`support_type + focus` ويعالج الجزء المتعثر فيه فقط، دون إعادة درس أو مستوى كامل.

## الفهم المقروء والوسائط

في الشرح والتدريب يمكن استخدام الصوت للمساعدة. إذا كان اختبار الدرس يقيس **فهم المقروء** فلا نشغل قراءة النص تلقائيًا؛ حتى لا يتحول القياس إلى فهم مسموع.

## التوافق مع V1

نعيد استخدام أنواع الأسئلة والتفاعلات الموجودة أولًا، مع الاحتفاظ بمسار الاختبار القبلي/البعدي والمراجعات الصوتية. إدخال قالب الفيديو أو نوع خطوة تعليمية جديد للـRuntime يحتاج خطة تنفيذ وترحيل واختبارات مستقلة؛ **هذه الوثيقة ليست تعديلًا على الكود المنشور**.
