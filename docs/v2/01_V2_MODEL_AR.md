# هِمّة V2 — النموذج التعليمي المعتمد

**الحالة:** معتمد  
**التاريخ:** 2026-10-08

## الهدف

V2 تطوير متوازن فوق هِمّة الحالية، وليس إعادة بناء للمنصة من الصفر.

التحسين الأساسي هو نقل المحتوى من نشاط يعتمد أساسًا على أسئلة إلى **درس حقيقي**:

```text
اختبار قبلي
→ تحديد نقطة البداية
→ درس
   → تمهيد
   → شرح
   → أمثلة متعددة
   → تدريب موجه
   → تطبيق جديد عند الحاجة
   → تحقق مستقل
→ استمرار أو دعم
→ اختبار بعدي
```

## المبادئ

1. الطالب من الصف الثالث؛ L1 تأسيس علاجي وليس إعادة تدريس منهج الصف الأول.
2. لا نشرح كل الحروف أو الظواهر حرفًا حرفًا؛ نستخدم أمثلة ممثلة ثم نعالج الفجوة الدقيقة بالدعم.
3. الدرس يعلّم مفهومًا أو استراتيجية، وليس سؤالًا أو مثالًا واحدًا.
4. أمثلة الشرح متعددة وتختلف عن أمثلة التحقق.
5. التدريب الموجه يسمح بالتلميح والتصحيح وإعادة المحاولة.
6. التحقق المستقل يستخدم لاتخاذ قرار الاستمرار أو الدعم.
7. خطأ واحد لا ينشئ دعمًا ولا يخفض مستوى الطالب.
8. لا automatic demotion لمستوى كامل.
9. الفجوة من مستوى سابق تعالج داخل المسار الحالي متى أمكن.
10. L1/L2/L3 تبقى مسارًا عامًا واضحًا.
11. نعيد استخدام بنية ومحتوى V1 حيث يخدم V2.
12. لا نبني Mastery Engine أو CMS كاملًا قبل إثبات الحاجة.

## المستويات

- **L1 — تأسيس علاجي:** حرف/صوت، حركات، مقاطع، دمج، كلمات بسيطة.
- **L2 — الكلمة والجملة:** بناء وكتابة كلمة، مدود، كلمات أطول، قراءة وفهم الجملة، بناء جملة.
- **L3 — النص والفهم والكتابة:** جمل مترابطة، نص قصير، فهم، ترتيب أحداث، فكرة رئيسة، بناء وكتابة جملة.

## الحجم المعتمد

- 13 Skill Groups.
- 19 Core Lessons.
- 12 Support Groups.
- Pretest = 30.
- Posttest = 30.
- تحقق Core = 3–5 بنود، الافتراضي 4.
- تحقق Support = 2–3 بنود.

## ما لا نفعله

- لا نعيد تعليم الأبجدية كاملة.
- لا نحول كل subskill إلى Skill مستقلة.
- لا ننشئ درسًا مستقلًا للسكون أو الشدة.
- لا نجعل سرعة القراءة هدفًا مستقلًا.
- لا نخلط التدريب بالتقييم.
- لا نجعل Advanced ASR شرطًا لإطلاق باقي V2.
