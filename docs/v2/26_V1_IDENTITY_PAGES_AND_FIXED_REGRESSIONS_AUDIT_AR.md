## 6. خطة اختبار التصميم لكل الصفحات (لا تنتهي بتقارير فقط)

لكل `PGxx` ومعها الحالات الحرجة:
1. **Desktop 1440px، tablet 768px، هاتف 360/390/430px، Zoom 200%، RTL**؛ فحص horizontal overflow، النصوص الطويلة، تركيز، touch targets، تباين، شاشة فارغة.
2. **الهوية:** الشعار/الأيقونة والألوان والخطوط والرسوم/الشخصية تبقى متناسقة وتحمّل سريعًا دون قص أو حجب.
3. **التدفقات:** زر العودة/التالي، حفظ وخروج/استئناف، الخطأ، التنبيه، التحميل البطيء، تسجيل صوت، keyboard/microphone permissions، سلوك الفشل والتكرار.
4. **صور V1 المحفوظة:** مقارنة التحديث بصورة المصدر/الحالة المقصودة؛ الاختلاف البصري مقبول إذا تحسّنت الوظيفة، **الاختفاء أو التلف لا يُقبل**.
5. **Quality Evidence:** screenshot للصفحة/الحالات المحورية وPlaywright/CI على SHA واحد بعد آخر تغيير؛ ليس فقط لقطة الصفحة الرئيسية.
6. **المشرف:** عرض/إدارة الطلاب والتقارير والتصدير والمراجعات والإعدادات والملف الشخصي والإشعارات؛ لا تسقط هذه الصفحات إذا لم تتغير المهارات التعليمية.
7. **مقارنة المشاكل القديمة:** سجل RG01–RG25 بجانب PG01–PG17 وفحص regression صريح، ويُحظر إغلاق المرحلة إذا كانت P0/P1 المهمة قد عادت.

**أصل التصميم الجديد:** `StudentShell/StudentTaskShell/QuestionRenderer/VideoPlayer` و`AdminShell/AdminUI primitives` مع مصدر tokens واحد. **التغيير جذري في بنية مكونات الواجهة لا في هوية المشروع أو وظائفه**. لا CSS ترقيع جديد يعالج صفحة وينكسر في غيرها.

## 7. حالات مسموحة فقط في سجل التتبع

`observed_in_v1_code | historical_claim_fixed | historical_open | new_v2_implementation_required | verified_on_v2_preview | retained_with_qa | retire_approved`.

**معيار إغلاق P01:** تسجيل كل صفحة وأصل ومشكلة قديمة ومعرّف المصدر، وتحديد اختبار قبول للنسخة الجديدة. **إغلاق التنفيذ لاحقًا:** لا يُكتب `verified_on_v2_preview` قبل تشغيل الصورة/الوظيفة فعليًا، ولا يُعتبر وجود Commit سابق أو تقرير نجاح تاريخي كافيًا.
