## كيفية تعامل العامل
- دورك مجدول آليًا بواسطة ChatGPT، وليس GitHub Actions Cron؛ لا تخلق Cron مكررًا في GitHub لتجنب عملين لنفس الدور.
- الجدولة لا تضمن زمن انتهاء التشغيل أو توافر أدوات الكتابة؛ تأكد بنفسك من GitHub connector قبل كل دورة، ودون `BLOCKED_CONNECTOR` إذا تعذر.
- لا تكرر الدورة لمجرد رؤية تشغيل سابق جارٍ. عملك مشروط بالحالة والـlease في `CONTROL.json`.
- لا تتعامل مع الوكيل الآخر كشخص له ذاكرة مشتركة؛ **GitHub هو وسيط التسليم الوحيد**.
- بدأ التشغيل المجدول لا يعني إنهاء المهمة. التقرير المختوم بالـCommit هو دليل التنفيذ الفعلي.
- لا تعتمد على `next_run_time` لأنه قد لا يظهر فور الإنشاء في خدمة المهام؛ مصدر الحقيقة للجدول هو `DTSTART/RRULE` والحالة `is_enabled=true`.
