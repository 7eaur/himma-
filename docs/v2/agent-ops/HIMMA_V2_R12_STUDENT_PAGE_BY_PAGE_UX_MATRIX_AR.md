## قواعد قبول التجربة (معيار «هل هكذا يبنيها خبير؟»)

1. في كل شاشة يجب أن تكون **خطوة الطفل التالية واحدة وواضحة**؛ لا مفاهيم تطوير أو معلومات خادم، ولا إجراء نقر بلا استجابة.
2. راجع المقاسات 320، 360، 390، 430، 768، 1024، 1280، 1440، وكذلك 200% zoom، RTL، النصوص العربية والتشكيل، تبويب لوحة المفاتيح، تباين الألوان، أهداف النقر 44px.
3. اختبر حالات **التحميل والفراغ والخطأ والانقطاع وإعادة الاتصال وفقد تأكيد الحفظ**، والفروق بين طالب جديد/متابع/بانتظار مراجعة/مطلوب إعادة تسجيل/أكمل؛ لا استبدال نتيجة رسمية بإحصاءات V1.
4. لا ترجع الأزرار الطالب إلى بداية اختبار أو درس حفظ تقدمه، ولا تظهر أخطاء SQL/JSON/تفاصيل API للطفل، ولا يتسرب اسم أو صوت طالب سابق بعد تسجيل الخروج أو تبديل الجلسة.
5. الصور والشرح والتلميحات والتقوية والفيديو والصوت تنتهي إلى محتوى تعليمي حقيقي، بلا بطاقات متكررة أو نصوص تطوير. تأجيل فيديوهات الدروس الفردية وASR لا يُستخدم ذريعة لإظهار محتوى وهمي.

## ترتيب الدفعات المقبلة (لا نبدأ نشرًا ثانيًا قبل إغلاق البوابة الحالية)

1. **S01 دخول الطالب:** المراجعة البرمجية والاختبار الجاريان أعلاه؛ عند نجاح CI/M04/M09 على SHA واحد فقط، تُراجع رقعة Railway المتاحة وتُنشر على Web/API الأصليتين ويُفحص التشغيل بعد النشر.
2. **S02 خريطة الدروس:** رفض استجابة 200 الفاسدة بأخطاء عربية آمنة مع زر إعادة محاولة؛ إلغاء إرسال رسائل API الخام؛ حماية نتيجة الطلب القديم بعد تبديل المسار أو فك تركيب الشاشة؛ اختبار الحالات الفارغة/الانقطاع/403.
3. **S03 لوحة الطالب:** نقد الترتيب والتكرار والنصوص، 320–1440px، جميع حالات طالب جديد/بانتظار صوت/إعادة تسجيل/مكتمل، دون ازدحام.
4. **S04 الاختبارات والدروس والتقوية:** فحص المشغّل على شبكات بطيئة، حالة استمرار التقدم، التلميحات والتقوية، تركيب الحروف المتصلة، حالات فقد تأكيد الحفظ.
5. **S05 الصوت والمكافآت والخصوصية:** صلاحيات الميكروفون وSafari/Android، صوت واحد حالي لكل نشاط، قرار المشرف، النجوم والشارات دون تضخيم؛ فحص عدم تسرب حساب آخر.
6. **S06 تدقيق شامل ونشر وتسليم:** إزالة نصوص تطوير متبقية بلا تعطيل حواجز V2، اختبار بصري وتفاعلي، توثيق SHA وأدلة الإنتاج، إعادة المراجعة النهائية قبل اعتماد العميل.

**القرارات التي لا تتغير:** V2 فقط للطالب، لا كتابة حرة، لا حسابات تجربة إضافية في الإنتاج، لا فروع معاينة، لا خدمات Railway إضافية، لا إعلان نتائج اختبارات قبل انتهائها.
