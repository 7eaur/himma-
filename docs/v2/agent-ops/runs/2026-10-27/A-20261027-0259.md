## Root cause and scope
The server already rejects `video_ended` if reported progress is below 90%. The player lacked the matching front-end guard, so a premature native event could send a doomed completion request and show a misleading save-retry prompt. A duplicate `ended` event just after pressing replay also restored the completed overlay even though playback had restarted. This patch changes only the player and its regression tests, preserving the server-side validation and existing idempotent save semantics.
