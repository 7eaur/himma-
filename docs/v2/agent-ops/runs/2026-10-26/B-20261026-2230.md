## Root cause and rationale
Previously `logout()` waited for the POST before navigation and always redirected in `finally`, including HTTP 503. The previous learner's name and dashboard remained visible while the network stalled; a failed logout could appear successful even though the cookie was not confirmed cleared. A concurrent pretest start POST could also navigate back into the old learner's assessment after logout. The patch keeps the page privacy-neutral from the click, treats non-2xx as unconfirmed logout with a retry, and ignores stale pretest responses. Server-side authorization remains authoritative. Tests use only synthetic V2 data.
