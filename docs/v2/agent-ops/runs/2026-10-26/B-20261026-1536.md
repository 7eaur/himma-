## Root cause and scope

The keyed `AssessmentV2Session` isolates React state but the prior asynchronous `load()` continued after unmount and could call `router.replace("/student/login")` when a late GET returned 401/403. The patch cancels in-flight GET on cleanup/replacement, ignores aborted or superseded responses before any redirect or state mutation, and keeps the existing strict GET/POST payload checks. A dashboard link is available during pending recovery so navigation away can occur without waiting for network timeout.

The new Playwright test creates a synthetic student and pretest, injects a malformed first GET to show retry, holds the second GET, follows the real Next Link to the dashboard, then releases a 401 and checks that the dashboard remains visible rather than redirecting to login. The test does not prove actual-device navigation or cross-student identity switching; those remain open. No main/stage/V1/ElevenLabs/ASR changes, no Railway settings touched.
