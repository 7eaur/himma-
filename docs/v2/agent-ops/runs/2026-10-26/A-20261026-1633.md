## Root cause and correction

`MediaRecorder.start()` may succeed and an asynchronous `error` event may occur later (microphone disconnected/encoder failure). Previously only `ondataavailable` and `onstop` were handled, so the UI could stay in recording mode or turn partial audio into a Blob. The new handler stops all tracks, cancels callbacks before stopping the recorder, clears chunks/Blob/URL, resets the recording state and displays a retry message. Unmount now detaches `onerror` as well. Test uses a synthetic stream and event; it is not real-device proof.
