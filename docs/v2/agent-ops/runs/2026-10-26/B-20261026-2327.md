## Root cause and limits
The learner start handler used React state (`starting`) alone to prevent concurrent POSTs; a second handler invocation before state commit could send a duplicate start request. It also accepted zero, negative, or unsafe integer session IDs as long as `Number.isInteger` passed. The patch adds a synchronous ref and checks `Number.isSafeInteger(id) && id > 0`. No backend score, content, or authorization rule changed. No live browser result is claimed.
