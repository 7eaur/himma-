## 6. قاعدة الوثائق والأدلة

- هذا الملف هو الخطة والتسليم وقائمة المتبقي الوحيدة. README وCURRENT_STATUS وTASK_QUEUE والـhandoffs القديمة تحيل إليه بدل قوائم متنافسة.
- DECISIONS عقد قرارات، وبنوك JSON مصدر محتوى، ومصفوفة المتصفح معايير فحص؛ ليست خططًا موازية. التقارير المؤرخة أدلة محدودة بالـSHA، وتاريخ النصوص المستبدلة محفوظ في Git.
- كل إغلاق يسجل: المشكلة → السبب → الملفات → الاختبار → CI/SHA → النشر → Work/DB → الحدود. لا كلمات مرور أو أكواد دخول أو أصوات أطفال أو نسخ DB في Git.
- قبل المتابعة افحص HEAD وRailway؛ قد يكون HEAD توثيقيًا والنشر على كود أقدم. لا reset لعمل غير مرتبط ولا حذف لأصول تعليمية.
