# هِمّة V2 — القرارات المعتمدة الحالية

**التاريخ:** 2026-10-08  
**الغرض:** سجل مختصر للقرارات التي تحكم V2 الحالية فقط.

## C-001 — V2 تطوير فوق V1

نحتفظ بالبنية الحالية قدر الإمكان ونطورها تدريجيًا. لا إعادة بناء شاملة قبل ثبوت الحاجة.

## C-002 — الدرس وحدة تعليم حقيقية

```text
تمهيد
→ شرح
→ أمثلة متعددة
→ تدريب موجه
→ تطبيق جديد عند الحاجة
→ خلاصة
→ تحقق مستقل
```

أمثلة الشرح لا تستخدم حرفيًا كاختبار، والدرس لا يشرح مهارة كاملة بمثال واحد.

## C-003 — التأسيس علاجي

الطالب صف ثالث. L1 يعالج فجوات ولا يعيد تعليم الأبجدية كاملة.

## C-004 — 13 Skill Groups

نعتمد 13 Skill Groups تشغيلية، مع Evidence Types وError Tags خفيفة عندما نحتاج تفريقًا أدق.

## C-005 — 19 Core Lessons

### L1 — 6
1. الحرف وصوته.
2. التمييز بين الحروف والأصوات المتشابهة.
3. الحركات القصيرة.
4. قراءة المقاطع القصيرة.
5. دمج الأصوات والمقاطع.
6. قراءة الكلمات البسيطة.

### L2 — 6
1. بناء وكتابة كلمة بسيطة.
2. المدود والصوت القصير والطويل.
3. قراءة كلمات أطول ومتعددة المقاطع.
4. قراءة جملة قصيرة بنطق صحيح.
5. فهم معنى الجملة مباشرة.
6. بناء جملة بسيطة من كلمات.

### L3 — 7
1. قراءة جمل مترابطة بنطق صحيح.
2. قراءة نص قصير بنطق صحيح.
3. فهم المعلومات المباشرة في النص.
4. ترتيب أحداث النص.
5. تحديد الفكرة الرئيسة.
6. بناء وإكمال جملة ذات معنى.
7. كتابة جملة قصيرة.

## C-006 — 12 Support Groups

1. الحرف والصوت والتمييز.
2. الحركات القصيرة.
3. المقاطع والدمج.
4. الكلمات البسيطة.
5. بناء وكتابة الكلمة.
6. المدود.
7. الكلمات الأطول.
8. قراءة الجملة/النص والقراءة الجهرية.
9. الفهم المباشر.
10. ترتيب الأحداث.
11. الفكرة الرئيسة.
12. بناء وكتابة الجملة.

نستخدم `support_type + focus` بدل شجرة Variants كبيرة.

## C-007 — التكيف المبسط

- خطأ واحد لا يسبب Support.
- لا Automatic Demotion.
- الأداء غير المستقر يمكن أن يحصل على فرصة موجهة أو تحقق قصير.
- الضعف الواضح والمتكرر يقود إلى Support.
- فجوة المستوى السابق تعالج داخل المسار الحالي قدر الإمكان.

## C-008 — القياس

- Pretest = 30.
- Posttest = 30.
- Core Check = 3–5، الافتراضي 4.
- Support Check = 2–3.
- التدريب الموجه لا يعد تحققًا مستقلًا.
- يعاد Mapping بنود V1 على Skill Groups الجديدة.

## C-009 — القراءة والصوت

الطلاقة المقصودة هي صحة النطق والدقة والقراءة الطبيعية المناسبة، لا السرعة وحدها.

التسجيل يستخدم عندما تكون قراءة الطالب نفسها هي الدليل. المراجعة البشرية تبقى السلطة الحالية إلى أن يعتمد تحليل آلي موثوق.

## C-010 — الوسائط

لا فيديو إجباري لكل درس. نستخدم الصوت والصورة والتفاعل والـMicro-animation حيث يضيف كل منها قيمة تعليمية فعلية.

## C-011 — AI

يبقى AI مكوّنًا واضحًا في V2، مثل تحليل القراءة أو تصنيف الخطأ أو اقتراح الدعم، لكن Advanced ASR + Alignment + C/D/I/S + Phoneme ليس شرطًا لإطلاق بقية V2.

## C-012 — CMS والهندسة الثقيلة

يؤجل CMS الكامل وMastery/Confidence Engine وDependency Graph الكامل حتى تثبت الحاجة. الأولوية للدروس والمحتوى والتكيف العملي.

## C-013 — إعادة استخدام V1

المحتوى والبنية الحالية يصنفان إلى reuse / edit / guided practice / independent check / support / retire. لا يعاد بناء كل شيء تلقائيًا.

## C-014 — لا تغيير للإنتاج قبل Migration

لا يتحول تخطيط V2 إلى Runtime production قبل خطة ترحيل واختبارات قبول واضحة.
