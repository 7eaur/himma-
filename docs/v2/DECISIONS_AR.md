# Himma V2 — سجل القرارات

**الغرض:** تسجيل القرارات الجوهرية لمسار V2 حتى لا تتغير ضمنيًا أو تضيع بين المحادثات.

---

## D-001 — اعتماد مسار V2 مستقل عن إصلاحات النسخة الحالية

**التاريخ:** 2026-10-07  
**الحالة:** معتمد

- يتم تطوير تصور Himma V2 على فرع مستقل.
- لا يغيّر هذا الفرع Runtime الإنتاج الحالي.
- لا يُدمج V2 قبل اكتمال المحتوى والتكيف والمعمارية وخطة الترحيل والاختبارات.

**السبب:** منع خلط إصلاحات النسخة الحالية مع إعادة تصميم التجربة التعليمية.

---

## D-002 — اعتماد نموذج الدروس التكيفية الهجينة

**التاريخ:** 2026-10-07  
**الحالة:** معتمد

المسار العام:

```text
اختبار قبلي
→ تحديد نقطة البداية
→ درس
→ تدريب موجه
→ أسئلة ما بعد الدرس
→ قرار تكيفي
→ درس تالٍ أو تقوية
→ انتقال تدريجي
→ اختبار بعدي
```

**السبب:** تحقيق تكيف أكثر دقة من النظام القديم دون إعادة بناء كاملة قائمة على ملف Mastery معقد.

---

## D-003 — الإبقاء على L1 / L2 / L3

**التاريخ:** 2026-10-07  
**الحالة:** معتمد مبدئيًا

- L1: التأسيس.
- L2: بناء الكلمة والقراءة.
- L3: الجمل والطلاقة والفهم.

التوزيع التفصيلي للمهارات على هذه المستويات يؤجل إلى المرحلة 03.

---

## D-004 — اعتماد ستة محاور تعليمية رئيسية فقط

**التاريخ:** 2026-10-07  
**الحالة:** معتمد للتخطيط

1. الحروف وأصواتها.
2. الحركات والمقاطع.
3. قراءة وبناء الكلمات.
4. المدود والكلمات الأطول.
5. الجمل والطلاقة والفهم.
6. الكتابة والتعبير البسيط.

لا تتحول الصور أو الاستماع أو الترتيب أو الإدراك أو التذكر تلقائيًا إلى محاور مستقلة؛ تستخدم غالبًا كطرائق تعلم وتمارين مساندة.

---

## D-005 — الفصل بين التعليم والتدريب والقياس

**التاريخ:** 2026-10-07  
**الحالة:** معتمد

- **الدرس:** يعلّم المهارة.
- **التدريب الموجه:** يسمح بالممارسة والمساعدة والتصحيح.
- **أسئلة ما بعد الدرس:** تنتج الدليل الأساسي لقرار التكيف.

لا يعتمد الانتقال على التدريب وحده.

---

## D-006 — عدم اعتبار سؤال واحد دليل إتقان

**التاريخ:** 2026-10-07  
**الحالة:** معتمد

- الإجابة الصحيحة الواحدة لا تكفي لاعتماد Skill.
- الخطأ الواحد لا يبرر خفض الطالب مستوى.
- القرارات تعتمد على أدلة متكررة وبحسب أهمية المهارة والمتطلبات السابقة.

التفاصيل الرقمية تؤجل إلى Adaptive Rules.

---

## D-007 — المحتوى القديم مادة مرشحة لا مرجعًا ملزمًا لـ V2

**التاريخ:** 2026-10-07  
**الحالة:** معتمد

كل عنصر قديم سيخضع لاحقًا للمراجعة، وقد:

- يبقى.
- يعاد صياغته.
- ينقل.
- يدمج.
- يتحول إلى تدريب أو تقييم أو تقوية.
- يستبعد إذا لم يعد يخدم هدفًا واضحًا.

---

## D-008 — لا يبدأ التغيير المعماري قبل تثبيت المحتوى والتكيف

**التاريخ:** 2026-10-07  
**الحالة:** معتمد

الترتيب الملزم:

```text
النموذج التعليمي
→ المهارات
→ المستويات
→ الدروس
→ الوسائط
→ التدريب
→ التقييم
→ التقوية
→ التكيف
→ مراجعة القديم
→ المعمارية
→ الترحيل
→ التنفيذ
```

**السبب:** منع تصميم قاعدة البيانات أو APIs حول تصور تعليمي غير مستقر.
