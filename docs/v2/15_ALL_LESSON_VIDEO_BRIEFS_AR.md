# هِمّة V2 — توجيهات إنتاج الفيديوهات التعليمية (ملف واحد)

**الحالة:** بطاقات تأليف معتمدة الشكل، **محتوى قيد المراجعة وليس فيديو منتجًا**؛ إنتاج الفيديوهات منفصل. تاريخ التحديث: 2026-10-15.

يجب أن يعلّم الفيديو المهارة، بأمثلة من 1 إلى 3، دون إعادة أسئلة التقييم أو تقديم إجاباتها، ودون سيناريو مشاهد مفصل. الفيديو المطلوب لكل درس أساسي مستقل، لا ملف تعليمات مستقل.

## L1-01 — الحرف وصوته

- **الهدف:** أربط الحرف بصوته عند رؤيته أو سماعه.
- **المهارة:** S1؛ ما يجب أن يتعلمه الطالب: يعرض الصوت المناسب لكل حرف، ثم يبدأ من الصوت للوصول إلى الحرف. يجب التفريق بين اسم الحرف وصوته. لا شرح للأبجدية كاملة.
- **الأمثلة:** م — مَوْز؛ ب — بَاب؛ س — سَمَك.
- **التدريبات بعد الفيديو:** listen_choose_one / sound_to_letter؛ choose_one / letter_to_sound.
- **اختبار الدرس يقيس:** letter_to_sound، sound_to_letter؛ عدد المعروض 4 دون تلميح.
- **الوسيط:** `VID-L1-01` — `missing_new`؛ لا يُنشر الدرس قبله.

## L1-02 — أميز الحروف والأصوات المتشابهة

- **المهارة:** S1؛ ما يجب أن يتعلمه الطالب: المقارنة بالنقاط أولًا ثم بالأصوات المتقاربة، دون تفصيل مخارج الحروف.
- **الأمثلة:** ب / ت / ث؛ ج / ح / خ؛ س / ص.
- **التدريبات بعد الفيديو:** choose_one / visual_discrimination؛ listen_choose_one / auditory_discrimination.
- **اختبار الدرس يقيس:** visual_discrimination، auditory_discrimination؛ عدد المعروض 4 دون تلميح.

## L1-03 — الحركات القصيرة

- **الأمثلة:** بَ / بُ / بِ؛ مَ / مُ / مِ؛ سَ / سُ / سِ.
