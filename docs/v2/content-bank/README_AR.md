# بنك التأليف التعليمي — هِمّة V2

هذا المجلد يحفظ **مسودات بيانات التأليف فقط**، ولا تتصل تلقائيًا بالإصدار المنشور أو قاعدة البيانات.

- `L1_AUTHORING_BANK_DRAFT.json`: 6 دروس L1 + 4 مجموعات دعم أولية + 66 بندًا مؤلفًا؛ عدد التدريب والاختبار لكل درس 4 + 4.
- وسائل V1 مستعملة مرشحة للمراجعة من المالك لاحقًا؛ المفقود مسجل دون إنشاء مسارات وهمية.
- نصوص الطالب العامة بلا تشكيل، والمقاطع والكلمات المقروءة لها تشكيل هادف حيث يخدم المهارة.
- فيديوهات الدروس مرحلة إنتاج منفصلة، ومطلوب لكل درس فيديو رئيسي قبل النشر.
- ملفات `15` إلى `19` هي فهارس المحتوى والوسائط والمتابعة المجمعة.

**لا تنقل هذه الملفات مباشرة إلى runtime.** يلزم مراجعة تربوية وتحويل لاحق بعقد نشر مستقل.
