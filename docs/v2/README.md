## الهدف

هذا المجلد هو المرجع الوحيد لتخطيط Himma V2 قبل التنفيذ.

V2 ليست إعادة بناء للمنصة من الصفر. هي تطوير متدرج فوق النظام الحالي لتحويل الأنشطة إلى دروس حقيقية وتحسين الدعم والتكيف والقياس مع أقل تعقيد ضروري.

## Baseline المعتمد

- **13 Skill Groups**
- **19 Core Lessons**
  - L1 = 6
  - L2 = 6
  - L3 = 7
- **12 Support Groups**
- Pretest = 30
- Posttest = 30
- Core Check = 3–5 بنود، الافتراضي 4
- Support Check = 2–3 بنود
- تطوير adaptation الحالي بدل استبداله
- Evidence/Error Tags خفيفة بدل Mastery Engine كبير
- AI واضح، لكن Advanced ASR ليس blocker
- بنك محتوى مستقل عن الواجهات بأربع مجموعات (دروس/أسئلة/دعم/وسائط)؛ CMS الكامل مؤجل
- القالب الأحدث للدرس: تمهيد → فيديو شرح وأمثلة → تدريب بتلميحات → اختبار مستقل

## قاعدة الحقيقة

- Runtime الحالي يبقى منفصلًا حتى تنفيذ Migration مع اختبارات.
- لا تعتمد وثائق V2 المحذوفة أو التاريخية كمصدر قرار.
- Git history يحتفظ بالتاريخ عند الحاجة، لكن الملفات الموجودة في `docs/v2` هي المرجع الحالي.
- أي تعديل مستقبلي جوهري يحدث هذه الوثائق معًا ولا ينشئ خطة موازية جديدة.

## حالة التأليف الفعلي

بدأ التأليف الفعلي في `11_ACTUAL_CONTENT_AUTHORING_AR.md`.

- ✅ `L1-01 — الحرف وصوته`: مؤلف فعليًا.
- ✅ `L1-02 — أميز الحروف والأصوات المتشابهة`: مؤلف فعليًا.
- ✅ `SUP-01 — الحرف والصوت والتمييز`: مؤلف فعليًا بثلاثة Focus فقط (`sound_mapping`, `visual_confusion`, `auditory_confusion`).
- ✅ تم توثيق القالب الجديد وبنك المحتوى، وتجهيز نموذج بيانات `L1-01` في المثال المشار إليه أدناه.
- ⏭️ التالي **بعد مراجعة واعتماد النموذج**: اختبار القالب على `L2-01` و`L3-03`؛ ثم استكمال `L1-03` و`SUP-02`.

## اعتماد القوالب وبنك المحتوى — 2026-10-15

القرار الحالي المعتمد: **أربع مراحل ظاهرة للطالب** (تمهيد، فيديو تعليمي، تدريب بالتلميحات، اختبار مستقل)، وبنك بيانات منفصل عن الواجهة. الشرح والأمثلة والخلاصة تُعد داخل سيناريو فيديو الدرس؛ هذا تحديث على شكل العرض الموصوف في الملفات السابقة، وليس إلغاء لأهدافها التعليمية.

- بعد مراجعة عينة L1-01 نختبر قابلية إعادة الاستخدام مع L2-01 وL3-03، **ثم** نكمل تأليف بقية البنك.
