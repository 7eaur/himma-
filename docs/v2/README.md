## الغرض

هذا المجلد هو نقطة الحقيقة الخاصة **بتصميم Himma V2 قبل التنفيذ**.

لا يستبدل عقود Runtime الحالية ولا يعني أن V2 منشورة أو مدمجة. الغرض هو تثبيت القرارات التعليمية والمحتوى والتكيف أولًا ثم اشتقاق المعمارية والتنفيذ منها بصورة منظمة.

## قاعدة العمل

- لا نبدأ بالكود قبل تثبيت المحتوى والسلوك المطلوب.
- لا نضيف Skill أو Lesson أو Question بلا هدف تعليمي واضح.
- لا نغير قرارًا معتمدًا بصمت؛ يسجل التعديل في `DECISIONS_AR.md`.
- لا نكرر الحالة في ملفات كثيرة. هذا الملف هو فهرس المرحلة، والملفات المرقمة تحمل التفاصيل.
- المحتوى القديم مادة مرشحة لإعادة الاستخدام، وليس قيدًا على V2.
- الإنتاج الحالي منفصل عن هذا المسار حتى وجود خطة Migration واعتماد صريح.
