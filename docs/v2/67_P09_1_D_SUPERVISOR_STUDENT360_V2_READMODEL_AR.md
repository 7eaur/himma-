# P09.1-D — صفحة المشرف Student360: مصدر V2 مستقل عن أرشيف V1

**نطاق هذا التنفيذ:** واجهة `apps/web/src/app/admin/(dashboard)/students/[id]/page.tsx`، لا إعادة كتابة للمنصة، لا تعديل لنظام التقييم أو السجلات القديمة.

## ما تغير في شاشة المشرف
- التبويب الافتراضي الجديد «مسار هِمّة V2» مصدره `GET /v2/student/admin/students/{id}/home` الذي يقرأ رحلة V2 المثبّتة والجلسات الرسمية؛ لا يستخدم `Student.current_level` القديم في احتساب مستوى V2.
- الملخص العلوي أصبح يعرض مستوى V2 المعتمد، نسبة إكمال الدروس المعينة وطلبات المراجعة لا نجوم أو تقدّم V1. `null` يُعرض «غير معتمد»، بلا درجة صفرية وهمية.
- نتائج القبلي والبعدي لا تظهر كنسب إلا عند `official=true` مع وجود `score_percent`، وبدون عرض المفاتيح الخاصة للإجابات أو صوت الطفل.
- تبقى صفحات الأرشيف V1 وقراراتها التاريخية متاحة تحت تبويباتها؛ تمت إعادة تسمية عناوينها بوضوح لتجنب اعتبارها بيانات المسار الجديد.
- يتطابق `student.id` مع `id` الحالي قبل اعتماد قراءة V2، وتُلغي AbortController طلبات الصفحة السابقة عند التنقل السريع؛ فشل V2 يُعرض خطأ مستقلًا مع إعادة المحاولة، ولا يرجع تلقائيًا إلى أرقام V1.
- إدارة التسجيلات والمراجعة عبر روابط صفحات المشرف V2 الحالية؛ لا يتم إظهار صوت لم يكتمل تقييمه في ملخص الطالب.

## المتبقي وعدم المبالغة
هذا تنفيذ طبقة مصدر البيانات الملخصة وليس قائمة كاملة لكل سؤال في الدروس الـ19 ولا مراجعة الصوت على نفس شاشة Student360. يلزم لاحقًا تنظيم بطاقات تاريخ الدروس/المهارات والإشراف على مراجعات الصوت بأدلة أوسع. لا تعتمد الدفعة قبل فحوص TS/Jest/E2E وM04/M09 للـHEAD.
