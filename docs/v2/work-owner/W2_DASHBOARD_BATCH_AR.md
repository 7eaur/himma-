# W2 — دفعة توحيد النظرة العامة وعزل الأرشيف

الفرع V2 فقط، 2026-10-27. هذه دفعة جزئية ضمن W2، ليست إعلان إغلاق لوحة المشرف كلها.

## تغييرات فعلية

- endpoint مشرف `/v2/student/admin/overview` ببيانات V2: إجمالي الحسابات/النشط، رحلات الدروس، المكتمل، مراجعات الاختبارات/الدروس، التسكين والجاهزون للبعدي، وأحدث ستة طلاب. الإحصاءات تشمل كامل العينة مستقلّة عن pagination؛ لا رمز دخول ولا درجات V1 أو مفاتيح إجابات.
- صفحة `/admin` تستخدم المصدر الجديد وحده؛ لا أكواد في الجدول أو بطاقات الهاتف، ولا أنشطة 0/10، ولا صفر مزيف عند تعطل API. حالات loading/error/retry/empty صريحة.
- تسجيلات V1 خلف disclosure «أرشيف V1 التاريخي» في sidebar، وتبويبات V1 داخل ملف الطالب لا تظهر افتراضيًا. تقارير V1 الأخرى ما زالت تحتاج نقل/إحلال ضمن W3؛ لم نزعم إغلاقها.
- لا تطلب Student360 مصادر journey/rewards/adaptation التاريخية حتى فتح الأرشيف. عمليات الحساب المشتركة محفوظة. قراءة ملف الحساب القديم ما زالت مشتركة مع إدارة الاسم/الرمز؛ فصلها إلى عقد صلاحيات أقل جزء متابعة W2.
- فُصلت نقطة التسكين الأصلية عن current_level المتغير عند حساب تقدم V2: لا تتحول دروس L1 المكتملة إلى skipped عند انتقال الطالب إلى L2. المرجع PlacementDecisionV2 للإصدار المثبت؛ fallback قديم يحفظ الدرس المكتمل كتعلم، دون اختراع نتيجة.
- اختبارات V1 E2E تفتح disclosure صراحة قبل التبويب التاريخي، مع إبقاء جميع فحوص الوظائف والبيانات والصلاحيات السابقة.
- أضيف W1 E2E حقيقي: إنشاء حساب اصطناعي، legacy pretest start دون فتح سؤال، دخول واجهة الطالب ثم استكمال نفس session_id في V2 وإعادة تحميل. لقطة CI في p09-v2-home/w1-empty-legacy-shell-resumed.png عند نجاح التشغيل.

## الاختبارات والقيود

- TypeScript وESLint ناجحان؛ Jest 16 suites/136 PASS قبل آخر تعديل lazy archive؛ API targeted 50 PASS.
- full backend محلي أولًا أصيب بقاعدة SQLite مؤقتة malformed schema؛ أوقف التشغيل، حُفظ log، ثم شغلت المجموعات على ملف اختبار منفصل ونجحت. إعادة full suite على SQLite مستقلة قيد التنفيذ. لا اتصال بقاعدة إنتاج ولا حذف بيانات مستخدم.
- متصفح Work أثبت الطالب الجديد سؤال 1 ثم حفظ إجابة واستعادة سؤال 2/30. أداة screenshot أظهرت الصورة تفاعليًا، لكن بعض الملفات المحفوظة عادت blank عند فتحها محليًا؛ **لم تُرفع كأدلة**. لقطة ملف الطالب الاصطناعي الأولى محفوظة ومفحوصة فعليًا. يلزم استكمال ملفات صور حالات الطالب من CI أو التقاط ناجح لاحق.
- W1 وW2 لا يُغلقان قبل CI/M04/M09 للـSHA والاختبارات الحية؛ جميع الصفحات/300 بند/المكافآت/P10 ما زالت مفتوحة وفق المصفوفة.
