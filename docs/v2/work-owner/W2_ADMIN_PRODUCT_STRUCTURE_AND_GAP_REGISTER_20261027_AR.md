# تنظيف لوحة هِمّة ومسار الطالب — جرد التنفيذ والبوابات

**قرار المنتج:** هِمّة الحالية هي المنتج الوحيد الذي يراه الطالب والمشرف. إزالة «الأرشيف التاريخي» تعني إزالة كل مدخل وصفحة وعرض V1 من واجهة التطبيق، لا مسح سجلات الأطفال القديمة أو ملفات الصوت أو مفاتيح التدقيق في قاعدة البيانات. لا يستعمل V1 مصدرًا بديلًا لقرار أو درجة أو مكافأة حالية.

## هيكل لوحة المشرف المستهدف

| القسم | وظيفة واضحة | التنفيذ في هذه الدفعة | بوابة القبول الباقية |
|---|---|---|---|
| الرئيسية | أعداد الطلاب الرسمية وما يحتاج إجراء وروابط قصيرة | نظرة عامة V2 فقط، عنوان ونسق تنقل مبسط | متصفح مصادق للحالات فارغة/ممتلئة/خطأ/mobile |
| الطلاب | قائمة وبحث وإضافة ثم ملف مستقل | أسماء بلا V1؛ ملف الطالب: حالة، مستوى، تقدم، خطوة حالية، قبلي/بعدي، تفاصيل 19 درسًا والنجوم داخل أقسام اختيارية؛ الحساب في تبويب منفصل | جميع حالات التسكين والتقوية ومراجعة الصوت والحساب عبر المتصفح |
| المراجعة | الاختبارات والتسكين، قراءات الدروس، التسجيلات المقيّمة | ثلاثة مداخل مستقلة بلا تسميات مراحل التطوير أو «أرشيف»؛ تحفظ مراجعة الأدلة | استماع وتقييم وطلب إعادة ومراجعة لاحقة على حسابات اختبارية |
| النتائج | تقرير الدفعة/الفرد والمهارات الرسمية | تقارير V2 فقط مع Excel/PDF وملخص مهارات منفصل | مقارنة قبل/بعد ومفقود/معلق وملف تصدير على المنشور |
| المحتوى والوسائط | بنك 300 سؤال/33 قسمًا، تمهيد الدرس، الخيارات والمرجع الخاص، 89 أصلًا | فهرس الأقسام مجمع إلى قبلي/3 مستويات/تقوية/بعدي؛ الأسئلة مطوية افتراضيًا؛ رابط مباشر لمعرض الوسائط؛ يظهر الفيديو المشترك مؤقتًا | تدقيق 300 سؤال، 19 تمهيدًا، 12 تقوية، فحص الفيديو والصوت والصور عبر الأجهزة |
| الإعدادات | حساب وأمان ومشرفون | تبويباتها الحالية تعمل بعقد `/api/researcher` لحساب المشرف فقط | المصادقة والأدوار وتغيير كلمة المرور/الخطأ/الرجوع |

## تعارضات مفتوحة لا تُعد مغلقة بهذه الدفعة

| المعرف | الدليل في الكود | العمل المطلوب بالترتيب |
|---|---|---|
| HV2-UI-01 — أُصلح بالكود، قبول المتصفح معلّق | `/admin/audio-review` كانت صفحة V1 مباشرة تستعمل `/api/review/pending-audio` و`/api/recordings/play-by-key` | تحولت الصفحة إلى `/admin/v2-assessments`؛ نُقلت اختبارات الروابط واللقطات إلى مسار المراجعة الحالي. تحقق التشغيل المصادق على المعاينة ما زال مطلوبًا. |
| HV2-UI-02 — أُصلح بالكود، قبول المتصفح معلّق | `/student/session/[id]` و`/student/activity/[id]` كانا يعرضان واجهة وأسئلة V1 مباشرة؛ `StudentRerecordTasks` القديم كان يشير إليهما | الآن الرابطان يوجهان إلى مسار الطالب الحالي `/student` دون إعادة استخدام ID تاريخي لجلسة V2. أزيلت المكونات والأنماط القديمة غير المستعملة، وحولت اختبارات الشاشات الحرجة إلى التقييم القبلي V2. عقد مهام إعادة التسجيل V2 مفصول في `StudentRetryTasks`، ويبقى فحصه الفعلي مطلوبًا. |
| HV2-UI-03 | `settings` يستعمل `/api/researcher/*` لهوية المشرف؛ `account` يعيد التوجيه للإعدادات | فحص فصل عقود الحساب عن تقارير/سجلات V1، ثم إغلاق المسارات التي تعرض بيانات V1؛ لا حذف جدول الحسابات. |
| HV2-API-01 | ما زالت واجهات `/assessment/start` و`/review/pending-audio` و`/researcher/content-preview` القديمة موجودة في API، ولا تستدعيها واجهات V2 النشطة بعد إغلاق المداخل أعلاه | منع إنشاء رحلات V1 جديدة في وضع المنتج النهائي مع إبقاء قراءة السجلات الموثقة لأغراض الاستعادة/التدقيق الإداري خارج تجربة المنتج. إعادة اختبار الترحيل والنسخ الاحتياطي قبل الإغلاق. |
| HV2-CNT-01 | `/admin/content-preview` للقراءة والمعاينة فقط، كما كانت صفحة V1 المرجعية للقراءة فقط؛ فهرس الأقسام أصبح مجمعًا مع فتح السؤال عند الحاجة | قبول تجربة التنقل عبر 33 قسمًا على الهاتف والمتصفح؛ تحرير/استيراد المحتوى يتطلب قرار نشر إصدار جديد مستقل ولا يُفعّل على snapshot قائم. |
| HV2-MED-01 | 19 فيديو مؤقتًا مشتركًا، و2 صوت اختياري غير مستخدم بلا ملف | إنتاج الملفات الفردية لاحقًا؛ فحص اللفظ/الحقوق/الترجمة/الصوت والأجهزة. يعتمد قرار المالك الحالي المؤقت ولا يصير فيديو كل درس النهائي. |
| HV2-QA-01 | فرع المعاينة المعزول على Railway يملك Postgres فقط؛ إنشاء API رُفض بسقف موارد الخطة | توفير حد موارد معاينة معزولة، نشر SHA مجتاز، فحص 23 مسارًا/300 سؤال/19 درسًا/12 دعمًا عبر Work، لقطات للحالات، ثم بوابات P09/P10. |

## ما أزيل من المنتج الآن

حُذفت مكونات `LegacyContentPreview`, `LegacyReports`, `LegacySkillReports` غير المستعملة، وأزيلت لغة V1/الأرشيف من تنقل اللوحة وملف الطالب وقائمة الطلاب. لم تُحذف جداول أو سجلات أو تسجيلات V1. هذه دفعة تنظيم أولى، وليست ادعاء اكتمال تنظيف المسارات المباشرة المذكورة أعلاه.

## نتائج الفحص وحدوده

فحص واجهة الكود وتحليل طلبات كل صفحة؛ بعد إغلاق مداخل الطالب القديمة: Jest كامل **28 suites / 164 PASS** (استبدلت اختبارات UI القديمة باختبارات منع الوصول والرحلة الحالية)، TypeScript وESLint للملفات المتغيرة PASS، Playwright `--list` PASS، `git diff --check` PASS. هذه ليست نتيجة E2E فعلية. فحص المتصفح على الرابط المنشور لا يثبت هذه التغييرات لأنه مربوط بفرع آخر. لا دمج ولا اعتماد نشر نهائي حتى يجتاز فرع المعاينة اختبارات الاستخدام المصادق وتصدر موافقة المالك.
