# تنظيف لوحة هِمّة ومسار الطالب — جرد التنفيذ والبوابات

**قرار المنتج:** هِمّة الحالية هي المنتج الوحيد الذي يراه الطالب والمشرف. إزالة «الأرشيف التاريخي» تعني إزالة كل مدخل وصفحة وعرض V1 من واجهة التطبيق، لا مسح سجلات الأطفال القديمة أو ملفات الصوت أو مفاتيح التدقيق في قاعدة البيانات. لا يستعمل V1 مصدرًا بديلًا لقرار أو درجة أو مكافأة حالية.

## هيكل لوحة المشرف المستهدف

| القسم | وظيفة واضحة | التنفيذ في هذه الدفعة | بوابة القبول الباقية |
|---|---|---|---|
| الرئيسية | أعداد الطلاب الرسمية وما يحتاج إجراء وروابط قصيرة | نظرة عامة V2 فقط، عنوان ونسق تنقل مبسط | متصفح مصادق للحالات فارغة/ممتلئة/خطأ/mobile |
| الطلاب | قائمة وبحث وإضافة ثم ملف مستقل | أسماء بلا V1؛ ملف الطالب: حالة، مستوى، تقدم، خطوة حالية، قبلي/بعدي، تفاصيل 19 درسًا والنجوم داخل أقسام اختيارية؛ الحساب في تبويب منفصل | جميع حالات التسكين والتقوية ومراجعة الصوت والحساب عبر المتصفح |
| المراجعة | الاختبارات والتسكين، قراءات الدروس، التسجيلات المقيّمة | ثلاثة مداخل مستقلة بلا تسميات مراحل التطوير أو «أرشيف»؛ تحفظ مراجعة الأدلة | استماع وتقييم وطلب إعادة ومراجعة لاحقة على حسابات اختبارية |
| النتائج | تقرير الدفعة/الفرد والمهارات الرسمية | تقارير V2 فقط مع Excel/PDF وملخص مهارات منفصل | مقارنة قبل/بعد ومفقود/معلق وملف تصدير على المنشور |
| المحتوى والوسائط | بنك 300 سؤال/33 قسمًا، تمهيد الدرس، الخيارات والمرجع الخاص، 89 أصلًا | فهرس الأقسام مجمع إلى قبلي/3 مستويات/تقوية/بعدي؛ الأسئلة مطوية افتراضيًا؛ رابط مباشر لمعرض الوسائط؛ يظهر الفيديو المشترك مؤقتًا | تدقيق 300 سؤال، 19 تمهيدًا، 12 تقوية، فحص الفيديو والصوت والصور عبر الأجهزة |
| الإعدادات | حساب وأمان ومشرفون | تبويباتها الحالية تعمل بعقد `/api/researcher` لحساب المشرف فقط | المصادقة والأدوار وتغيير كلمة المرور/الخطأ/الرجوع |

| HV2-QA-01 | فرع المعاينة المعزول على Railway يملك Postgres فقط؛ إنشاء API رُفض بسقف موارد الخطة | توفير حد موارد معاينة معزولة، نشر SHA مجتاز، فحص 23 مسارًا/300 سؤال/19 درسًا/12 دعمًا عبر Work، لقطات للحالات، ثم بوابات P09/P10. |

## ما أزيل من المنتج الآن

حُذفت مكونات `LegacyContentPreview`, `LegacyReports`, `LegacySkillReports` غير المستعملة، وأزيلت لغة V1/الأرشيف من تنقل اللوحة وملف الطالب وقائمة الطلاب. لم تُحذف جداول أو سجلات أو تسجيلات V1. هذه دفعة تنظيم أولى، وليست ادعاء اكتمال تنظيف المسارات المباشرة المذكورة أعلاه.

## نتائج الفحص وحدوده

فحص واجهة الكود وتحليل طلبات كل صفحة؛ Jest كامل **26 suites / 166 PASS**، TypeScript وESLint لمجلد لوحة المشرف PASS، `git diff --check` PASS. فحص المتصفح على الرابط المنشور لا يثبت هذه التغييرات لأنه مربوط بفرع آخر. لا دمج ولا اعتماد نشر نهائي حتى يجتاز فرع المعاينة اختبارات الاستخدام المصادق وتصدر موافقة المالك.
