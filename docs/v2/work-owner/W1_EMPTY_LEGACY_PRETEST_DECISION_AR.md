2026-10-27، بتوقيت عدن. تفويض المالك: إصلاح البداية مع حفظ V1 التاريخي.

## السبب المثبت حيًا

فحص Work للملف رقم #2 بعد نشر التشخيص `f074969b`: جلسة #2، V1، قبلي، غير مكتملة، **صفر محاولات ودون نتيجة رسمية**. الحساب الجديد #3 المنشأ من لوحة المشرف يصل إلى بداية القبلي؛ ودخل فعليًا للسؤال الأول ثم حفظ إجابة واستعاد السؤال الثاني بعد reload عبر Cloud Browser. لذلك إنشاء الحساب الجديد ليس هو الذي ينشئ التاريخ؛ الحاجز الحالي يعامل مجرد shell V1 كأنه دليل أكاديمي.

## القرار والتنفيذ

- القراءة GET لا تعدّل شيئًا. تعرض start_pretest فقط عندما تكون هناك جلسة واحدة بالضبط، قبلي V1 نشط، المحاولة الأولى، دون supersession أو نتيجة أو مستوى معتمد أو وقت مسجل أو حالة V2، ودون أي Attempt حتى غير المجاب أو مسودة/إجابة V2 أو PlacementDecision أو رحلة/درس.
- عند **ضغط الطالب ابدأ**، نفس قفل الطالب المستخدم في مساري V1/V2 يعاد تحته التحقق من جميع الشروط. تُستكمل الجلسة نفسها ببيانات V2 المثبتة على الإصدار. يبقى session_id وstarted_at ورقم المحاولة. تُحفظ جميع أعمدة السجل الأصلي في AuditLog `v2.pretest.empty_legacy_adopted` قبل التعديل. لا DELETE ولا إنهاء وهمي لجلسة V1 ولا احتساب درجة/إنجاز تاريخي.
- أي دليل فعلي ولو Attempt غير مجاب، وقت مسجل، نتيجة صفرية رسمية أو غير رسمية، جلسة مكتملة، عدة جلسات، أو رحلة موجودة: **لا استكمال تلقائي**، تبقى مراجعة المشرف وتفويض الإعادة الصريح.
- إعادة POST تعيد جلسة V2 نفسها ولا تكرر journey أو audit. لا تغيير للتسكين أو قواعد التقييم أو مراجعة الصوت.

## لماذا تغير اختبار V1 القديم؟

الاختبار السابق كان يسمي shell بلا محاولة أو وقت «historical attempt». أصبحت حالة shell هي الانحدار المستهدف للإصلاح. بقي رفض التاريخ باختبار مستقل فيه elapsed_seconds=1، وأضيف اختبار يحفظ Attempt حقيقيًا حتى قبل الإجابة ويثبت رفض أي استكمال. لا تعطيل اختبارات ولا حذف توقع أمني بلا بديل أقوى.

## بوابة الحالة

نجاح اختبار أول دخول جديد في المتصفح مثبت على `f074969b`، وليس إثباتًا لتطبيق الإصلاح اللاحق على الحساب #2. لا يُعد W1 مغلقًا قبل بوابات SHA الجديد والتحقق الحي من ظهور start_pretest للحالة الفارغة؛ الحساب التاريخي الفعلي لا يُستخدم لكتابة إجابات أو تبديل بياناته في الاختبار. يختبر استكمال shell في fixture اصطناعي.
