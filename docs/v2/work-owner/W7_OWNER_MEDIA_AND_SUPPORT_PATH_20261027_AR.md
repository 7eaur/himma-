## كيف يرى الطفل التقوية

1. تمهيد الدرس وعنوانه وهدفه → فيديو الدرس المؤقت → تدريب موجّه → تحقق مستقل. يظهر التمهيد قبل الفيديو بالفعل.
2. بعد خطأ في التحقق المستقل، تقرر الخدمة وفق أدلة المحاولة الرسمية: تحقق إضافي قصير (سؤالان)، أو تدريب تقوية مركز داخل الجلسة. لا تخفض المستوى تلقائيًا ولا تمنح نجومًا بسبب خطأ أو سرعة.
3. التقوية تعرض اسم المهارة ورسالة توضح المساعدة، ثم أسئلة التدريب مع تلميح عند الخطأ من الخادم، وبعدها تحقق التقوية بلا تلميح جواب. لا يوجد فيديو للتقوية، ولا تعيد مشاهدة فيديو الدرس قسرًا. في التعثر المستمر يظهر انتظار تدخل المشرف مع حفظ الدليل.
4. شخصية هِمّة تظهر في كل سؤال بتعليمات وتشجيع، وتتحول إلى وضع «جرّب مرة أخرى» مع تلميح التدريب الموجّه بعد الخطأ. الاختبار القبلي/البعدي والتحقق المستقل لا يظهران صحة الإجابة أو تلميحًا أثناء التقييم. يبقى التلميح مرئيًا خلال اختيار المحاولة التالية.
