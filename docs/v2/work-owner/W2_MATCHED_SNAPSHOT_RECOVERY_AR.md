# W2 — استعادة أصل البنك المطابق من Git

## التطابق المثبت

Work Cloud Browser عرض للجلسة المتعذرة release_id=1، version=`himma-v2-authoring-0.3-draft+b78f8b01cdf0`، checksum=`b78f8b01cdf00b9b0c9e311fb424d24c1bb286a0066fefb48fb6639235c2b085`.

أُعيد بناء إصدارات compiler والبنوك من 15 نقطة تغيير في Git منذ 20 أكتوبر. أربع بصمات أصلية متميزة؛ النسخة المطلوبة طابقت تمامًا مخرجات المصدر عند `2100143cda6d2b06d76009951d59f02dd07f497e`. النقطة التاريخية ذات tree الناقص موثقة ورفضت ولم تُستخدم. لا توليد سؤال/جواب جديد ولا استخدام current bank مكان الأصل.

## التنفيذ المحدد

- نسخة compiler الأصلية الكاملة أُخرجت إلى ملف gzip حتمي mtime=0 داخل services/api/v2_content/historical_releases، بلا بيانات طالب/جلسة/تسجيل. ليست ملفًا عامًا في تطبيق الويب.
- endpoint المشرف `POST /v2/content/admin/releases/{release_id}/restore-original-snapshot` يقفل سجل الإصدار، يختار فقط البصمة المعروفة الموثقة، يعيد حساب SHA-256 لكامل payload الأصلي، ويقارن version/checksum بالسجل القائم.
- **إضافة فقط** إلى PrivateContentBankSnapshot مع AuditLog واحد؛ لا تغيير لجلسة/جواب/نتيجة/تسكين/إصدار عام/تفعيل محتوى. إعادة POST ترجع already_present. نسخة موجودة مختلفة أو بصمة/نسخة مجهولة أو ملف معدل: 409 بلا استبدال.
- زر «استعادة النسخة الأصلية المطابقة» لا يظهر إلا للمشرف في blocked item عند توفر النسخة المعروفة وغياب snapshot. بعد الاستعادة يعاد تحميل القائمة؛ لا اعتماد/تقييم تلقائي للتسجيل.
- البنك الأصلي يحفظ أنواع وأسئلة نسخته القديمة كما هي؛ لا إعادة تأليفها وفق بنك V2 الحالي. الطالب يستخدم تثبيت الجلسة الأصلي فقط.

## الاختبار

7 اختبارات API للاستعادة وعزل المراجعة: PASS. شملت استعادة original pending evidence ثم توفره للمراجعة، مرتين دون تكرار، عدم تعديل answer_json/session release/is_active، رفض الطالب، رفض بنك مجهول/ملف معدل/استبدال snapshot مختلف. TypeScript/ESLint PASS، Jest كامل قبل إضافة اختبار زر الاستعادة الأخير 17 suites/138 PASS؛ نتيجة الزر توثق لاحقًا.

## الحالة

الاستعادة البرمجية جاهزة؛ تطبيقها الحي لم يحدث عند كتابة هذه الوثيقة. يلزم نشر المعاينة، تشغيل الزر ثم التحقق من اختفاء blocked وظهور الدليل الأصلي **دون تقييمه**. لا قبول W2 أو P09/P10 شامل من هذا الإصلاح وحده.
