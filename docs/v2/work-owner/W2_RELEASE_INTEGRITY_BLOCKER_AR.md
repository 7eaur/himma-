# W2 — فقد نسخة بنك تاريخية يعطّل قائمة المراجعة

## الدليل الحي

بعد نشر `b69ddb50`، لوحة V2 أظهرت 1 قراءة اختبار معلّقة بينما النظرة القديمة عرضت صفرًا. فتح رابطها في Work Cloud Browser وصل إلى /admin/v2-assessments وظهر «النسخة الأصلية غير محفوظة؛ تم إيقاف التقييم لحماية الإجابات». ليست قائمة فارغة بالفعل، وليست مشكلة عدم وجود طالب جديد.

## السبب والإصلاح

كل من review_queue وlesson_queue كان يحل نسخ جميع الجلسات داخل loop؛ فشل جلسة واحدة يرفع 409 للاستجابة كلها ويخفي الطلاب الآخرين. الإصلاح يحافظ على fail-closed لكل دليل غير صالح، ويعيد blocked_items منفصلة ببيانات استعادة الإصدار فقط (رقمه/نسخته/بصمته ومعرفات السجل)، دون إجابات أو أصوات أو أزرار اعتماد لهذا الدليل. تبقى الأدلة الصحيحة في items، وتظل عمليات تقييم الدليل المتعذر مرفوضة 409.

الصفحات تعرض «سجلات تحتاج استعادة إصدار المحتوى»، وتخفي بيانات القائمة القديمة بعد فشل التحديث. حارس generation يمنع رد التصفية القديم من استبدال الأحدث أو تحديث الصفحة بعد مغادرتها. لم نغير النتيجة أو المحتوى المثبت لأي جلسة، ولم نستخدم current bank بديلًا.

## اختبار حقيقي للعزل

- API: جلسة سليمة + جلسة ببنك مختلف دون snapshot لكل من assessment وlesson؛ القائمة 200، السليم متاح، المتعذر ظاهر بلا جواب/رابط صوت، ومحاولة اعتماد المتعذر 409 وجميع الإجابات تبقى pending.
- مجموع اختبارات المراجعة والتقييم المستهدفة: 43 PASS.
- اختبارا واجهة فعلية المكونات يثبتان ظهور blocked مع منع الاعتماد وإخفاء البيانات القديمة بعد 503: 2 PASS؛ TypeScript/ESLint PASS.
- لقطة المتصفح لم تُحفظ لهذا السجل القائم حماية لبياناته؛ النص التشغيلي المنقح أعلاه هو الدليل الحالي.

## ما لم يُغلق

هذا يعالج عزل القائمة وإتاحة بقية المراجعات، **لا يعيد بناء البنك المفقود**. التالي قراءة version/checksum للسجل المتعذر عبر شاشة المشرف ومطابقته إلى Git history. لا نسجل BLOCKED_EXTERNAL نهائيًا قبل محاولة استعادة الأصل المطابق؛ إذا لم نجد النسخة المطابقة يلزم مصدر backup/export أصلي. لا يجوز تغيير content_release_id أو تقييم الإجابة ببنك اليوم.
