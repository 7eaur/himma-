# W3 — بنك V2 ومعرض الوسائط (دفعة وظيفية)

## المصدر والصلاحيات

- GET `/v2/content/admin/bank` للمشرف فقط، read-only، مصدره get_release المثبت للكود الحالي. 300 سؤال في 33 قسمًا: قبلي، 19 درسًا، 12 دعمًا، بعدي. ترتيب GP قبل IC/SC، مع التمهيد والهدف والتصفية والبحث وpagination. إجابات ومعايير القراءة للمشرف فقط؛ عقد الطالب الآمن لم يتغير.
- GET `/v2/lessons/admin/media/{asset_id}` يعرض أصول التعليم الثابتة للمشرف ولا يصل لتسجيلات الأطفال. المسار آمن من معرف السجل فقط، Cache-Control private/no-store وnosniff، مع TEST_ONLY header. production يرفض بدائل الاختبار غير المعتمدة.
- سجل 89 أصلًا يتضمن preview_url للمشرف؛ لا رفع/تعديل/اعتماد/حذف وسائط عبر هذه الواجهة.

## الواجهات

- /admin/content-preview صار بنك V2 افتراضيًا: الأسئلة والخيارات والجواب/المرجع، التمهيد، البحث والقسم والسابق/التالي. بنك V1 محفوظ خلف زر أرشيف صريح، ولا يطلب بياناته قبل فتحه.
- /admin/v2-media صار gallery responsive مع مرشح النوع والحالة والبحث بمعرف الأصل أو الدرس والاستخدامات. معاينة صوت/صورة/فيديو لا تحمل المصدر حتى ضغط المستخدم. الملف المشترك TEST ONLY ظاهر بوضوح ولا يُحسب جاهزية تعليمية.
- صور سؤال/خيار ضمن المعاينة للمشرف لا تستخدم روابط تشغيل الطالب التي كانت ترفض المشرف 403. فشل الوسيط يظهر حالة واضحة دون استبدال الأصل بملف مختلف.
- لم تنتقل تقارير V1 إلى V2 في هذه الدفعة؛ ما زالت ضمن W3 التالية. لم تُنفذ المكافآت أو تُعتمد الوسائط.
