## العقد التقني الملزم قبل القبول
- ledger V2 مستقل append-only، مع student/release/lesson-or-level/milestone ومفتاح فريد يمنع إعادة المنح على reload أو retry أو جلستين/تبويبين؛ policy_version للتدقيق، وليس ذريعة لإعادة منح الحدث عند تعديل العرض.
- المنح داخل transaction الحدث المحفوظ، مع AuditLog بلا جواب أو رمز أو تسجيل خاص. فشل transaction لا يترك منحة منفصلة.
- قراءة home أو المشرف لا تمنح ولا تصلح بيانات؛ مصدر عداد الطالب والمشرف ledger نفسه. إجمالي العرض لإصدار رحلة الطالب المثبت فقط؛ تاريخ الإصدارات وV1 يبقى منفصلًا.
- لا backfill يختلق فيديو أو GP أو حكم قراءة مفقودًا. إجراء مصالحة مشرف صريح يمكنه فقط إدراج استحقاق مثبت كامل من البنك الأصلي المحفوظ؛ لا overwrite ولا حذف منحة سابقة. snapshot متعذر = لا منح جديد.
- اختبارات القبول: كل milestone/replay/rollback/pending→graded/support/skip/L1-L2-L3/release mismatch/عدة جلسات/عزل طالب آخر/GET read-only؛ عرض الطالب والمشرف يطابق ledger.
