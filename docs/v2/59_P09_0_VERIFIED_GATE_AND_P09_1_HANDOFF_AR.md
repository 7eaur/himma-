## 5. عقد P09.1 المعتمد للتسليم الفني لا للتنفيذ

[58_P09_0_SOURCE_OF_TRUTH_CONTRACT_FOR_P09_1_AR.md](58_P09_0_SOURCE_OF_TRUTH_CONTRACT_FOR_P09_1_AR.md) يحدّد مصادر الحقيقة من الجداول وواجهات API التي فُحصت، دون اقتراح قاعدة جديدة:

- `StudentJourney.current_level/current_lesson_id` هو مصدر قرار رحلة V2 المبدئي؛ عدم خلطه تلقائيًا مع `Student.current_level`.
- `/v2/assessments/current-action` عقد الانتقال الحالي، يُختبر ويُدمج في StudentV2HomeDTO.
- الدروس من `LessonSession` والإصدار المثبت، والاختبارات من `AssessmentSession` الرسمية، والدرجات المعلقة = null لا صفر.
- `/api/rewards` القديمة ليست دفتر مكافآت V2. الشارات الجديدة تؤجل حتى نموذج events idempotent.
- المشرف يرى Student360 وتقرير Cohort بمصدر V2 وصلاحية مقيدة؛ ورمز دخول الطالب غير معروض افتراضيًا.
- لا تغيير أسماء الدوال القائمة ولا المساس بـP08 احتفاظ آخر صوت.

**مسار استلام التنفيذ القادم:** `P09.1-A` مراجعة current-action واختبارات حالات التسكين → `P09.1-B` read-models في Backend → `P09.1-C` لوحة الطالب V2 والفصل عن legacy → `P09.1-D` Student360 وتقارير المشرف → `P09.1-E` اختبارات الترحيل والصلاحية والتكامل واللقطات النهائية.
