# Himma V2 — Level Skill Map v1

**الإصدار:** 1.0  
**الحالة:** معتمد  
**تاريخ الاعتماد:** 2026-10-08

> هذه الوثيقة تحدد موقع المهارات الـ19 داخل L1/L2/L3 وعلاقات الاعتماد بينها وكيف تُعالج الفجوات دون إرجاع الطالب إلى مستوى سابق كامل.

---

## 1. مبدأ المستويات

المستويات ليست صناديق مغلقة.

المستوى يحدد **المسار العام ودرجة صعوبة المحتوى**، بينما يمكن لمهارة أن:

- تبدأ في مستوى.
- تستمر في المستوى التالي.
- تصبح في مستوى أعلى مهارة دعم أو متطلبًا ضمنيًا.
- تعود كدرس دعم مدمج إذا ظهرت فجوة.

المبدأ:

```text
Level = المسار العام
Skill = القدرة المحددة التي نراقبها
Support = تدخل مدمج عند وجود فجوة
```

---

# 2. L1 — التأسيس

هدف L1 هو بناء الأساس الذي يسمح للطالب بالانتقال من الحرف والصوت إلى المقطع والكلمة البسيطة.

المهارات الأساسية في L1:

- SK-01 التعرف على الحروف.
- SK-02 ربط الحرف بصوته.
- SK-03 التمييز البصري بين الحروف المتشابهة.
- SK-04 التمييز السمعي بين الأصوات.
- SK-05 قراءة الحروف بالحركات القصيرة.
- SK-06 قراءة المقاطع القصيرة.
- SK-07 دمج الأصوات والمقاطع.
- SK-08 بداية قراءة كلمة بسيطة.

تدريب الكتابة في L1 يشمل الحرف والمقطع والكلمة بصورة تمهيدية، لكن Skill الكتابة الرسمية تبدأ لاحقًا من كتابة الكلمة.

---

# 3. L2 — بناء الكلمة والقراءة

هدف L2 هو تثبيت الانتقال من المقاطع والكلمات البسيطة إلى الكلمات الأطول وبداية الجملة والكتابة المنظمة.

المهارات الأساسية في L2:

- SK-08 قراءة كلمة بسيطة.
- SK-09 تركيب كلمة من حروف أو مقاطع.
- SK-10 قراءة المدود.
- SK-11 قراءة الكلمات متعددة المقاطع.
- SK-12 بداية دقة القراءة الجهرية في الجمل القصيرة.
- SK-13 بداية الفهم المباشر للجمل والنصوص القصيرة جدًا.
- SK-16 كتابة كلمة بسيطة.
- SK-17 بداية ترتيب كلمات لتكوين جملة صحيحة.

مهارات L1 تبقى موجودة كمتطلبات ودعم، لكنها لا تحتاج دروسًا أساسية مكررة للطالب الذي أثبت إتقانها.

---

# 4. L3 — الجمل والفهم والكتابة

هدف L3 هو استخدام القراءة بصورة أكثر استقلالية في الجمل والنصوص القصيرة وربط القراءة بالفهم والكتابة.

المهارات الأساسية في L3:

- SK-12 دقة القراءة الجهرية في الجمل والنصوص القصيرة.
- SK-13 الفهم المباشر.
- SK-14 ترتيب الأحداث أو الجمل.
- SK-15 تحديد الفكرة الرئيسة.
- SK-17 ترتيب كلمات لتكوين جملة صحيحة.
- SK-18 إكمال جملة ذات معنى.
- SK-19 كتابة جملة قصيرة.

مهارات الكلمات والمدود تبقى خلفية لازمة، وتعود فقط كدعم مدمج إذا ظهرت فجوة.

---

# 6. شبكة المتطلبات الأساسية

المسار التأسيسي الأهم:

```text
SK-01 التعرف على الحروف
→ SK-02 ربط الحرف بالصوت
→ SK-05 الحركات القصيرة
→ SK-06 المقاطع القصيرة
→ SK-07 الدمج
→ SK-08 قراءة كلمة بسيطة
→ SK-10 المدود / SK-11 الكلمات الأطول
→ SK-12 القراءة الجهرية
→ SK-13 الفهم المباشر
→ SK-14 / SK-15
```

وهناك مسار كتابة متوازٍ:

```text
تدريب حرف/مقطع في L1
→ SK-16 كتابة كلمة
→ SK-17 ترتيب كلمات لجملة
→ SK-18 إكمال جملة
→ SK-19 كتابة جملة قصيرة
```

SK-03 وSK-04 مهارتان داعمتان مهمتان، ولا يعني ضعف إحداهما وحده إلغاء كل تقدم الطالب.

---

# 7. كيف يعالج النظام فجوة من مستوى سابق؟

مثال:

طالب نتيجة قبليه تؤهله إلى L2، لكن لديه فجوة مثبتة في SK-06 قراءة المقاطع.

لا يصبح مساره:

```text
ارجع إلى L1
→ أعد L1
→ ثم L2
```

بل:

```text
L2 lesson
→ دعم مدمج لـ SK-06 في أقرب نقطة مناسبة
→ تحقق قصير
→ L2 lesson
→ استمرار طبيعي
```

إذا كان أول درس L2 يعتمد مباشرة على SK-06، يقدم الدعم قبله.

إذا لم يعتمد عليه فورًا، يمكن إدراجه بعد درس أو أكثر دون تعطيل المسار.

---

# 8. كيف يعالج النظام فجوة ظهرت أثناء المستوى؟

مثال:

طالب في L2 وظهر ضعف متكرر في SK-10 المدود.

الأصل:

```text
L2-04
→ دعم مدود
→ تحقق قصير
→ L2-05
```

ولا تؤجل الفجوة تلقائيًا إلى L3.

يجوز حملها إلى L3 فقط إذا كانت بسيطة، وغير حرجة، ولا تمنع تعلم بقية L2، وكان الطالب قد حقق شروط الانتقال الأخرى.

---

# 9. ما الذي يمكن أن يوقف محتوى بعينه؟

لا توجد قاعدة اسمها "فشل Skill = الرجوع مستوى".

الإيقاف يكون فقط عندما:

1. ثبت الضعف بأكثر من دليل مناسب.
2. المهارة متطلب مباشر للدرس التالي.
3. استمرار الطالب بدونها سيجعل التعلم التالي غير منطقي.

عندها:

```text
يوقف المحتوى المعتمد عليها فقط
→ يقدم دعم مدمج
→ تحقق قصير
→ يفتح المحتوى
```

---

# 10. العلاقة بالاختبار القبلي

الاختبار القبلي يجب أن يولد:

- نتيجة عامة تقترح المستوى.
- إشارات Skill لكل المهارات الـ19.
- حالات `needs_verification` عند عدم كفاية الدليل.
- قائمة فجوات أولية تندمج لاحقًا داخل المسار.

المعادلة:

```text
Overall placement
+
Skill evidence
+
Critical dependency check
=
Personalized starting sequence
```

---

# 11. ما لم يعتمد بعد

هذه الوثيقة لا تحدد:

- عدد الدروس في كل مستوى.
- عدد الدروس اللازمة لكل Skill.
- ترتيب الدروس التفصيلي.
- أسماء الدروس.
- عدد أسئلة كل Skill في القبلي أو بعد كل درس.
- نسب النجاح الرقمية.
- مدة الفيديوهات أو شكل الوسائط.

هذه البنود تبدأ في المرحلة التالية **04 — Lesson Map** وما بعدها.
