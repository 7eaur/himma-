# هِمّة V2 — القياس والأدلة

**الحالة:** معتمد من حيث الهيكل؛ العتبات الرقمية النهائية تؤجل لما بعد مراجعة المحتوى

## Pretest / Posttest

- Pretest = 30 بندًا.
- Posttest = 30 بندًا موازيًا في البنية والصعوبة.
- يحتفظان بوظيفتهما البحثية.
- يعاد Mapping بنود V1 إلى Skill Groups الجديدة.
- البنود الخارجة عن أهداف V2 تعدل أو تستبدل.

## بعد Core Lesson

- 3–5 بنود تحقق مستقل.
- الافتراضي 4.
- قد تكون 3 فقط إذا كان بينها تسجيل صوتي أو كتابة فعلية غنية بالدليل.
- قد تصل إلى 5 إذا احتجنا أكثر من نوع Evidence.
- لا نكرر أمثلة الشرح حرفيًا.

## بعد Support

- 2–3 بنود قصيرة.
- تركّز على الفجوة التي عولجت.

## التدريب ليس قياسًا نهائيًا

Guided Practice يسمح بـ:
- Hint.
- Feedback مباشر.
- إعادة المحاولة.

Independent Check:
- بدون مساعدة تعليمية مباشرة.
- يضيف Evidence للقرار.

## الأدلة

لا نحتاج Mastery Engine ثقيلًا. نحتفظ عند الحاجة بـ:
- skill_group
- evidence_type
- error_tag/focus
- result
- source lesson
- attempt/time

## التحقق الإضافي

إذا كانت الأدلة غير كافية، يمكن تقديم تحقق قصير إضافي. لا يلزم بناء Diagnostic State Machine كاملة في V2 الأولى.

## الصوت

التسجيل الصوتي يستخدم عندما تكون القراءة نفسها هي الدليل. السلطة الأكاديمية الحالية تبقى للمراجعة البشرية إلى أن يعتمد تحليل آلي موثوق.

## العتبات

لا تثبت هذه الوثيقة نسب نجاح/دعم جديدة الآن. تراجع بعد إنهاء محتوى الدروس وبنك التحقق، مع الاستفادة من قواعد V1 بدل تغييرها بلا دليل.
