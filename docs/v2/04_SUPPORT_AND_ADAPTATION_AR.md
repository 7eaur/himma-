# هِمّة V2 — الدعم والتكيف

**الحالة:** معتمد  
**الإجمالي:** 12 Support Groups

## الدعم

### L1

1. الحرف والصوت والتمييز.
2. الحركات القصيرة.
3. المقاطع والدمج.
4. قراءة الكلمات البسيطة.

### L2 الخاصة

5. بناء وكتابة الكلمة.
6. المدود.
7. الكلمات الأطول ومتعددة المقاطع.

### مشتركة مع L2/L3 وعليا

8. قراءة الجملة/النص والقراءة الجهرية.
9. الفهم المباشر.
10. ترتيب الأحداث.
11. الفكرة الرئيسة.
12. بناء وكتابة الجملة.

## Focus بدل Variants معقدة

لا ننشئ شجرة Variant تقنية كبيرة في البداية.

مثال:

```text
support_type = madd
focus = waw
```

أو:

```text
support_type = letter_sound
focus = visual_confusion
```

## مسار التكيف

```text
Core Lesson
→ Independent Check
→ أداء جيد: استمرار
→ أداء غير مستقر: فرصة موجهة/تحقق قصير
→ ضعف واضح ومتكرر: Support
→ Support Check
→ استمرار أو إجراء إضافي محدود
```

## قواعد

- خطأ واحد لا ينتج Support تلقائيًا.
- لا خفض تلقائي للمستوى.
- دعم سابق المستوى يدمج في المسار الحالي.
- الطالب لا يرى "رجوعًا" أو "ضعفًا".
- الدعم أقصر وأكثر تركيزًا من Core.
- الدعم يعيد التعليم قبل التحقق؛ لا يبدأ بسؤال مشابه لسؤال الخطأ.
- إذا استمر ضعف جوهري يمكن رفع الحالة للمشرف أو اتخاذ قرار محدود بدل بناء Loop لا نهائي.

## الاستفادة من V1

نطوّر Reinforcement/Adaptation الحالية بدل استبدالها بالكامل، ونستخدم Adaptation Decisions وReinforcement Cycles القائمة حيث يمكن.
