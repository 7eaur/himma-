# هِمّة V2 — Skill Groups والمستويات

**الحالة:** معتمد  
**التاريخ:** 2026-10-08

## الفكرة

تستخدم V2 عددًا صغيرًا من Skill Groups تشغيلية. عند الحاجة إلى تفاصيل أدق نستخدم Evidence Type أو Error Tag بدل إنشاء Skill وMastery State جديدين.

## L1

| ID | Skill Group | نطاقها |
|---|---|---|
| S1 | الحرف وصوته والتمييز | ربط الشكل بالصوت والتمييز البصري/السمعي عند الحاجة |
| S2 | الحركات القصيرة | الفتحة والضمة والكسرة |
| S3 | قراءة المقاطع والدمج | قراءة المقطع ودمج الأصوات/المقاطع |
| S4 | قراءة الكلمات البسيطة | قراءة كلمات بسيطة بصورة صحيحة |

أمثلة Error Tags لـS1:
- visual_confusion
- sound_mapping
- auditory_confusion

## L2

| ID | Skill Group | نطاقها |
|---|---|---|
| S5 | بناء وكتابة الكلمة | تركيب الكلمة وكتابتها |
| S6 | المدود | الألف والواو والياء والقصير/الطويل |
| S7 | قراءة الكلمات الأطول | كلمات متعددة المقاطع مع ظهور السكون والشدة طبيعيًا |
| S8 | قراءة الجملة وفهمها مباشرة | قراءة جملة قصيرة واستخراج معناها المباشر |

Evidence Types محتملة:
- word_construction
- word_writing
- sentence_reading
- sentence_direct_comprehension

## L3

| ID | Skill Group | نطاقها |
|---|---|---|
| S9 | دقة القراءة الجهرية | جمل مترابطة ونص قصير بنطق صحيح وطبيعي |
| S10 | الفهم المباشر للنص | استخراج معلومات صريحة |
| S11 | ترتيب الأحداث | التسلسل المنطقي لأحداث/جمل النص |
| S12 | الفكرة الرئيسة | تحديد الفكرة العامة الأساسية |
| S13 | بناء وكتابة الجملة | ترتيب، إكمال، ثم إنتاج جملة قصيرة |

## قواعد القياس

- الجمع في التعليم لا يعني دمج كل الأدلة في Score واحد.
- يمكن لدرس واحد أن يخدم أكثر من Evidence Type.
- لا نحتاج Confidence Score دائم لكل Skill في أول V2.
- Error Tags تستخدم لتوجيه الدعم لا لبناء شجرة مهارات ضخمة.

## التدرج

```text
S1/S2
→ S3
→ S4
→ S5/S6
→ S7
→ S8
→ S9/S10
→ S11/S12
→ S13
```

هذا تدرج إرشادي، وليس Dependency Graph تقنيًا إلزاميًا.
