## الفكرة والمستخدمون
منصة عربية باتجاه RTL لمساندة تلاميذ الصف الثالث الذين يواجهون صعوبات القراءة في سلطنة عُمان، بشعار «أتعلم، أتطور، أصل إلى القمة». يدخل الطالب برمزه، ويتابع المشرف الطلاب والمحتوى والوسائط والتسجيلات والنتائج. المنصة تعليمية ولا تقدم تشخيصًا طبيًا.

## رحلة التعلم
1. يبدأ الطالب الجديد باختبار قبلي من 30 سؤالًا. التسكين آلي بعد اكتمال التصحيح: أقل من 50% للمستوى L1، ومن 50% إلى أقل من 80% للمستوى L2، ومن 80% للمستوى L3.
2. يبدأ التعلم من المستوى المسكن فيه. يضم المحتوى 19 درسًا: 6 في L1، و6 في L2، و7 في L3، مع 12 وحدة دعم و300 سؤال تشمل القبلي والبعدي.
3. يمر الدرس بتمهيد وفيديو، ثم تدريب موجه وتحقق مستقل. تستخدم الأنشطة الاختيارات والصور والاستماع وترتيب الأحداث وتركيب الكلمات والقراءة الصوتية؛ لا تعتمد على كتابة حرة.
4. نجاح التحقق المستقل يسمح بالتقدم. فجوة واحدة تقود إلى تحقق إضافي، وتكرار الضعف في التركيز نفسه يفتح دعمًا مستهدفًا داخل المسار. الدعم ليس درس فيديو جديدًا. الأدلة التي تنتظر التصحيح لا تُحسب نجاحًا أو إخفاقًا مكتملًا.
5. يتابع المشرف التقدم والفجوات والمكافآت والنتائج، ويُتاح الاختبار البعدي وفق حالة الرحلة وصلاحيات النظام. لا تُطبق قواعد V1 القديمة على سياسة التقدم في V2.

## القراءة والتسجيلات
- القراءة مباشرة للحرف أو الكلمة أو الجملة المعروضة؛ البنك يحتوي 62 سؤال قراءة صوتية.
- المحرك الحالي يدعم Azure Speech، ويربط كل محاولة بالسؤال والنص المرجعي وإصدار المحتوى، مع متابعة النتائج في مركز المشرف. المسار الفعلي يتبع إعدادات البيئة وحالة المحاولة.
- إذا أعاد المزود نتيجة مفهومة غير مطابقة تُسجل إجابة خاطئة؛ لا تتحول تلقائيًا إلى طلب إعادة تسجيل. الإعادة التقنية عند التسجيل غير الصالح أو عدم رجوع نتيجة صالحة.
- مقارنة الكلمات والجمل نصية بعد التطبيع دون اشتراط التشكيل. التدريب يعرض تلميحات مناسبة، وتقييم الجمل يحتفظ بنسبة الكلمات الصحيحة وفق السياسة البرمجية.
- آخر تسجيل هو التسجيل المعتمد للعرض والمتابعة؛ تنظيف الملفات المستبدلة يتم بالآلية الموجودة بعد تثبيت الحالة. لا تُحذف سجلات الطلاب أو كائنات التخزين يدويًا ضمن تنظيف المستودع.

## البنية والتشغيل
| المسار | الوظيفة |
|---|---|
| `apps/web` | واجهة Next.js وReact ومسار وسيط محمي للـAPI |
| `services/api` | FastAPI ومنطق التعلم والتقييم والصلاحيات والتقارير |
| `services/api/alembic` | ترحيلات قاعدة البيانات اللازمة للإقلاع والترقية |
| `docs/v2/content-bank/*.json` | أربعة بنوك بيانات يقرأها البرنامج مباشرة؛ ليست توثيقًا زائدًا، ويجب الحفاظ على مساراتها وبصماتها |
| `packages` | بيانات المحتوى والعقود التي ما زالت تعتمد عليها أدوات ومنطق النسخة الحالية |
| `assets` و`apps/web/public` | الوسائط والخطوط والهوية المستخدمة |
| `deploy` و`scripts/ops` | أدوات النشر والنسخ الاحتياطي والاستعادة |

محليًا: شغّل الواجهة من `apps/web` بعد `npm ci` باستخدام `npm run dev`؛ للإنتاج `npm run build` ثم `npm run start`. ثبّت اعتماديات Python من `requirements.txt`، ثم شغّل من `services/api`: `python -m uvicorn main:app`. تتطلب البيئة إعداد اتصال قاعدة البيانات ومفاتيح التطبيق والتخزين والصوت بحسب ملفات البيئة النموذجية؛ لا تُحفظ القيم السرية في Git.
إنتاج Railway يتكون من Web وAPI وPostgreSQL وRedis والتخزين الخارجي. عنوان الواجهة: https://himma-web-production-eafd.up.railway.app . إعداد النشر الفعلي في Railway هو المرجع، بما فيه أوامر الترحيل والتهيئة؛ لا تُشغّل إعادة تهيئة بيانات الإنتاج ضمن التنظيف.
