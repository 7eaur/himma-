## عن المشروع

تساعد هِمّة الطالب على التعلم بحسب مستواه، من اختبار قبلي يحدد نقطة البداية إلى دروس تفاعلية وتدريب موجه وتحقق مستقل، مع دعم مستهدف عند تكرار الصعوبة. يتابع المشرف تقدم الطلاب والمحتوى والوسائط والتسجيلات والنتائج من لوحة موحدة.

واجهة عربية باتجاه RTL، متجاوبة مع الهاتف والحاسوب، وتعتمد تعليمات قصيرة وشخصيات تعليمية وتغذية راجعة مشجعة. المنصة تعليمية ولا تقدم تشخيصًا طبيًا.

## الوظائف الرئيسية

| المجال | ما تقدمه المنصة |
|---|---|
| رحلة الطالب | الدخول برمز، اختبار قبلي، تسكين آلي، دروس وتدريب وتحقق مستقل |
| التعلم التكيفي | متابعة الأدلة والفجوات وإدراج الدعم المستهدف داخل المسار |
| الأنشطة | اختيارات وصور واستماع وترتيب أحداث وتركيب كلمات وقراءة صوتية |
| القراءة الصوتية | ربط التسجيل بالسؤال والنص المرجعي وإصدار المحتوى، وتقييم عبر Azure Speech بحسب إعداد البيئة |
| لوحة المشرف | إدارة الطلاب والمحتوى والوسائط ومراجعة التسجيلات والنتائج والتقارير |
| تجربة الاستخدام | رسائل موحدة، حالات تحميل وإعادة محاولة، صفحة 404، وانتقالات خفيفة تراعي تقليل الحركة |
| الوسائط | 19 فيديو درس بدقة 480p، تحميل صور تدريجي، وكاش خاص للوسائط التعليمية |

## منطق التعلم

- يبدأ الطالب الجديد باختبار قبلي من **30 سؤالًا**. بعد اكتمال التصحيح: أقل من 50% للمستوى L1، ومن 50% إلى أقل من 80% للمستوى L2، ومن 80% للمستوى L3.
- يضم المحتوى **19 درسًا**: 6 في L1 و6 في L2 و7 في L3، مع **12 وحدة دعم و300 سؤال** تشمل القبلي والبعدي، منها **62 سؤال قراءة صوتية**.
- يتدرج الدرس من تمهيد وفيديو إلى تدريب موجه ثم تحقق مستقل. يعتمد التقدم على أدلة التحقق، ولا تُحسب المحاولات التي تنتظر التصحيح نجاحًا أو إخفاقًا مكتملًا.
- فجوة واحدة تقود إلى تحقق إضافي، وتكرار الضعف في التركيز نفسه يفتح دعمًا داخل المسار. الدعم ليس درس فيديو جديدًا، ولا توجد كتابة حرة في الأنشطة.
- إذا أعاد مزود الصوت نتيجة مفهومة غير مطابقة تُسجل إجابة خاطئة. إعادة التسجيل التقنية عند التسجيل غير الصالح أو غياب نتيجة صالحة.
- مقارنة الكلمات والجمل نصية بعد التطبيع دون اشتراط التشكيل، مع تلميحات في التدريب ونسبة الكلمات الصحيحة في تقييم الجمل.
- آخر تسجيل هو المعتمد للعرض والمتابعة، وتُدار الملفات المستبدلة عبر آلية الاحتفاظ في التطبيق.

تعمل بيئة الإنتاج على Railway بخدمتي Web وAPI، مع PostgreSQL وRedis وتخزين خاص للتسجيلات. تحفظ الواجهة جلسة المستخدم عبر المسار الوسيط، وتتحقق واجهات الخادم من الصلاحيات وملكية التسجيلات.

## التشغيل المحلي

المتطلبات: Python 3.12 وNode.js 22، مع PostgreSQL وRedis وتخزين متوافق مع S3. أوامر الأمثلة التالية من جذر المستودع ما لم يذكر غير ذلك.

1. انسخ `.env.example` إلى `.env` واضبط قيم التطوير المحلية، بما فيها قاعدة البيانات ومفتاح التطبيق والتخزين وحساب المشرف. طابق بيانات قاعدة البيانات مع إعداد Docker Compose.
2. شغّل الخدمات المحلية وثبّت اعتماديات الخادم:

   ```bash
   docker compose up -d
   python -m venv .venv
   # فعّل البيئة الافتراضية وفق نظام التشغيل.
   python -m pip install -r requirements.txt
   ```

   ملف القفل المعتمد هو `services/api/requirements.txt`؛ ملف الجذر يحيل إليه.

3. جهّز **قاعدة التطوير المحلية فقط**، ثم شغّل الخادم:

   ```bash
   cd services/api
   python -m alembic upgrade head
   python seed_all.py
   python -m db.seed
   python -m uvicorn main:app --reload
   ```

4. في طرفية أخرى شغّل الواجهة:

   ```bash
   cd apps/web
   npm ci
   npm run dev
   ```

   عنوان الواجهة `http://localhost:3000` والخادم `http://localhost:8000`. تستخدم الواجهة الخادم المحلي افتراضيًا؛ عند تغييره اضبط `NEXT_PUBLIC_API_URL` في بيئة الواجهة.

محرك القراءة يحتاج إعداد المزود والتخزين والعامل المناسب للبيئة. يبقى `HIMMA_V2_NATIVE_READING_ENABLED=0` في المثال المحلي حتى تجهيز الربط. لا تحفظ المفاتيح أو بيانات الطلاب أو تسجيلاتهم في Git.

## التحقق والصيانة

```bash
# من جذر المستودع: التحقق من بنوك محتوى V2 دون الكتابة لقاعدة البيانات.
cd services/api
python -m v2_content.compiler

# من جذر المستودع، وفي طرفية أخرى:
cd apps/web
npm run lint
npx tsc --noEmit
npm run build
```

- `assets/video/lessons/manifest.json` يربط الفيديوهات بالدروس ويتضمن بصمات الملفات. بيانات الأصول تصف الملفات الموجودة في كل حزمة.
- بعض أسماء المحتوى تتضمن V1 أو DRAFT لأسباب تعاقدية؛ تبقى ما دام التشغيل يعتمد عليها. وملفات المعاينة داخل `services/api/test_fixtures` مستخدمة في مسار الوسائط؛ ليست اختبارات مهملة.
- ترحيلات قاعدة البيانات وسجلات التعلم وملكية التسجيلات جزء من التشغيل. لا تُحذف أو تُعاد تهيئة بيانات الإنتاج ضمن تنظيف المستودع.
- النشر يستخدم إعداد Railway الفعلي؛ أوامر التهيئة أعلاه للتطوير. لا تشغّلها على قاعدة الإنتاج لمجرد تجهيز نسخة محلية.
- أداة إعادة ضبط حساب مشرف موجود: `scripts/ops/reset_researcher_password.py`. تُشغّل عند الحاجة فقط، بعد تحديد `DATABASE_URL` و`ADMIN_USERNAME` و`ADMIN_PASSWORD` صراحةً في البيئة.
